## Style standard and no planes: against the code before this change

Same machine, back to back, three 8 s runs each on a checkout of `b81c586` (the commit before the imaging and section work, `git archive`) and on the working tree
(960x540, synth5k, a duct riser selected, swiftshader; the run order alternated base, now, base, now; the first run of each page is the slowest while the machine warms up):

| code | frame interval ms per run | frame CPU ms per run |

Within noise (the machine was shared; the JS time is 1 to 1.5 ms in both). With the style standard and no planes the additions are a handful of uniforms, one `clipN > 0`
integer compare per fragment (never taken), one extra flat varying, and one `if (this.imaging)` per frame; no extra pass. The screenshot after visiting radiograph and MRI
and returning to standard is byte-for-byte identical to the one before (`bench/smoke-imaging.mjs`, both models); after clearing a section it matches within ghost-smoothing noise
(`bench/smoke-section.mjs`: no pixel differs by more than 12, mean 0.012 of 255).
