# WebXR, auto exposure and closed-solid caps: checks against the code before

Generated by hand from `bench/smoke-xr.mjs`, `bench/smoke-imaging.mjs`, `bench/smoke-section.mjs`, `bench/smoke-viewmodes.mjs`, `bench/help-smoke.mjs` and two scratch scripts
that ran the same scenes on a checkout of `HEAD` (`git archive`, the commit before this work) and on the working tree, back to back on one machine
(Chromium 1243 headless shell with swiftshader, viewport 1400 x 760).
**Swiftshader numbers are CPU rasterisation, not GPU numbers**; the frame interval is dominated by the software rasteriser and the machine was shared with other
processes, so read the JS time and small differences as noise.

## Frame cost, style standard, no planes, XR off

Three alternating runs each (8 s after 3 s warm-up, `app.frameLog`), old tree then working tree:

| scene | JS time per frame, old (ms) | JS time per frame, working tree (ms) | frame interval, old (ms) | frame interval, working tree (ms) |
| --- | --- | --- | --- | --- |
| synth5k, 5,000 elements | 1.13, 0.99, 1.81 (mean 1.31) | 1.26, 1.46, 1.61 (mean 1.44) | 646, 642, 856 | 660, 820, 706 |
| fzk-haus, 82 elements | 0.69, 0.88, 0.96 (mean 0.84) | 0.89, 0.99, 0.89 (mean 0.92) | 312, 283, 295 | 313, 314, 310 |

The spread inside one code version (0.99 to 1.81 ms for the old one) is larger than the difference between the versions. What the working tree adds per frame with the style
standard, no planes and no session: one `beforeFrame` check per plugin, `xrPresenting` (two property reads) in `render` and `renderScene`, one `clipPlanes` check in
`syncFocusDepth`, and one extra test per element in the state upload (the closed bit). The frame loop is three's `setAnimationLoop`, which calls `requestAnimationFrame`.

## Closed-solid flag (model load)

`computeClosedFlags` over the merged geometry, idle machine, four runs: 100,000 elements with 1,074,292 triangles in 74.6 to 79.7 ms (a loaded machine: up to 280 ms);
5,000 elements (synth5k, 24 vertices per box) 12 to 19 ms cold and 3.7 ms warm; fzk-haus (82 elements) 12 to 23 ms cold (the cost is the first call). Census of the three
bundled test models: every element counts as closed (the 8 elements of `building` with 3 to 9 unmatched edges of 78 to 150 are T-junctions, tolerated by the vector-area rule).

On the 22 m tall stack the picture without it sits in a band of 23 levels (10th to 90th percentile); with it the band is 67 levels wide and the floors, walls and columns are
distinguishable (`bench/imaging-synth-radiograph.png`, `bench/imaging-radiograph-classic.png`, `-negative.png`, `-fluoro.png`). The measurement reads a 64 x 64 grid back
asynchronously: no GPU stall warning, no console warning (`smoke-imaging` prints "no console errors or warnings").
