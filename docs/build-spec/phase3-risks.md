## 2. Open technical questions (orchestrator at wave 0 unless marked owner)

| # | Question | Default if undecided |
|---|---|---|
| T-1 | Does the replica mirror the whole scope or only the "take offline" selection? | The subscription scope (project, areas, record types) is mirrored; "take offline" adds pinned files and slices to the local cache |
| T-2 | Is `PendingCommand` an event or a table? | A table (`sync_pending_command`); `Sync.Reconciled` is the only local event, never pushed |
| T-3 | One readiness job kind or one per subject module? | One per module (`awp.readiness`, `testing.readiness`), one registry |
| T-4 | `ModelObject` as records or an operational table? | Operational table per revision; links from records carry the object id as a typed target, not a record id (a links-vocabulary question: `references` with `target_kind: model_object`) |
| T-5 | Where do the `xref_model_*` envelope slots go? | `schema/core/record.yaml` (a `schema/core/**` gate), nullable, no backfill |
| T-6 | Does the Issue engine own `Deficiency` escalation to NCR? | Yes: `raise_issue(..., source_record=deficiency_id)` with a `derived from` link |
| T-7 | Continuity: computed from `Weld.Welded` events per welder and process, or a log on the qualification? | Computed (a projection column `last_weld_on` per qualification); no manual log in Phase 3 |
| T-8 | Guest link OTP delivery (email, SMS)? | No delivery: the OTP is shown to the issuer, who passes it on; email delivery is a Phase 5 connector |
| T-9 | The pairing channel transport? | SSE on the existing change-feed route with a pairing filter; no WebSocket |
| T-10 | Legal items on replicas when the owner is cleared? | Never replicated, whatever the clearance (brief §22.6) |
| T-11 (owner) | Site node mode (I5 T08): build or defer? | See P3-Q1 |
