## Learnings (proposed)
- The ticket's Context list does not include `scenario.py` or `types.py`, but the escalation rule requires checking pasted signatures. I checked only the signatures with a targeted `rg` (`draw`, `CrewParams` fields, `SimContext` fields). They matched, so no block. A ticket could list those two files for signature checks, or say that a targeted grep is allowed.
- `FakeClient.query` in `testing.py` raises on any filter term other than `title~` and `status:`. The crew only needs `records(title_prefix=...)` with an empty query, which works, so keep that in mind if an actor needs a richer query in tests.
- The `Recorder.records` method returns records in key order, so `ctx.rng.choice(lines)` depends on key order. The provided pinned test depends on this too.
