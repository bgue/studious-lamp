## Learnings (proposed)
- `#fyi` is one of `DEFAULT_SIGNAL_TAGS`, so any post carrying it gets high importance and the `!` in its header (the core `effective_importance` rule). The snapshot's agent post shows `!` for that reason; this is correct, but the sketch does not show it, so a reader of the snapshot may take it for a rendering bug.
- Textual 8.2.8 `OptionList.set_options` and `clear_options` set `highlighted` to `None`, and `add_options` does not highlight anything on its own. The empty-state rule ("no highlight") therefore comes for free with `set_options`.
- The first run of a snapshot test with no baseline fails and writes `snapshot_report.html` into the worktree root. That file is an artefact and is not committed; delete it before committing.
- `just check` plus `just test-tui` together run about 2 minutes; a foreground Bash call with the default 120 s timeout moves to the background. Run them in the background or separately.
