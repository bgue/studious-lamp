## Learnings (proposed)
- The ticket's import list is not isort-clean as written: `from tl_sim.scenario import ...` must sit in its own block after the third-party imports (`yaml`, `pydantic`), or `ruff check` reports I001. `ruff check --fix <file>` fixes it and changes nothing else. Worth a line in the ticket template or in the learnings about tl-sim imports.
- `uv run ruff check --fix <file>` prints a notice that the file "was modified ... Call Read before editing", even though the edit was a deliberate fix from our own command. Harmless, but it looks like an external change.
