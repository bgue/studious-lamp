## Learnings (proposed)
- `just test` takes about 5 minutes (2758 tests). Redirect its output to a file and check the exit code, instead of relying on a short pipe.
- The ticket's Context list did not include the `tl_core` service signatures it pastes. Checking them (the escalation step) meant opening four more files. Listing `services/feed.py`, `feed_actions.py`, `feed_queries.py` and `feed/types.py` in Context would avoid that.
- The `ls` card line (`dev  dev created a record (KEY)`) repeats the actor because `render_card_summary` already puts the actor in the summary. The ticket's `item_line` format and test agree with this, so it is not a bug, but it reads oddly on first sight.
