## Learnings (proposed)
- The `Write` tool refuses to overwrite a file that was only read through `cat` in Bash; it needs a `Read` call first. Use `Read` on the file before editing or writing it, even when a shell read already showed the content.
- `ruff` (`I001`) sorts names within an import case-sensitively by plain string order, so `EffectiveProperty` comes before `EffectivePset`. The ticket does not mention import ordering, and the implementation has to match it or `just check` fails.
- Redirecting `just check` into a file and echoing `$?` on the next line kept the real exit code (1 on the failing run, 0 on the passing run). The ticket's warning about not piping into `tail` is correct; a file redirect avoids it.
