## Learnings (proposed)
- `just check` runs `ruff format --check .` over the whole repo, so running only `ruff check --fix` on the edited file is not enough; run `ruff format` on the edited file before `just check`. The ticket's step order (`ruff check --fix`, then `ruff format`) already implies this, but it is easy to skip when only the acceptance commands are read.
- The ticket does not say how the `N errors, M warnings` counts are derived. I counted `issue.severity == "error"` and `issue.severity == "warning"`; the provided tests pass with this.
