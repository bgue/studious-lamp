## Learnings (proposed)
- The provided test comment in `test_grid_c_opens_the_chooser...` says `CORE_COLUMNS` has 8 entries and the first pset is the 9th item. The tuple has 9 entries (`DEFAULT_COLUMNS` 5 plus 4 more), so `size_in` is the 10th item (index 9). The test uses `len(CORE_COLUMNS)` for the number of `down` presses, so it is correct, and only the comment is wrong. Supervisors editing future provided tests should count with `len()`, not by hand.
- In Textual 8.2.8, `query_one("#id", SelectionList[str])` raises `TypeError` at runtime (subscripted generics cannot be used in isinstance checks). Use the unsubscripted class in `query_one`, and subscript only in the class expression or the constructor call.
- `ModalScreen` attributes named `available` and `shown` work with this Textual version. The ticket's `shown` name needed no change.
- `uv run pytest packages/tl-tui -q` with a new provided test file whose module does not exist yet stops the whole package run at collection. Expected, but it hides the other results until the module exists.
