## Learnings (proposed)
- The Textual `Edit` tool refuses to edit a file that was only read through `Bash` (`cat -n`). It needs a `Read` call on that file first, even when the content is already in context.
- The ticket's Context list does not include the owner widgets (`RecordGrid`, `RecordView`, `EditForm`). The key-map owner test checks their bindings anyway, and all of them matched the table, so no key needed fixing. Still worth a note for future key-map tickets.
