## Learnings (proposed)
- `text.conformance_mark(None)` returns the string `"None"` (its fallback is `str(value)`). A record with no conformance value would therefore render `None` in the context panel. The provided sparse-record test does not exercise a missing conformance, so the tests pass. The supervisor may want `conformance_mark` to return `—` for `None`; I did not change `text.py` (outside *Allowed paths*).
- The ticket's Context list does not include `tl_tui/messages.py`, yet the interface names `NavSelected`. The provided test imports it and it already exists with the required constructor, so no read was needed. Worth noting when writing future tickets.
- `ruff format` runs before `ruff check --fix`, but the E501 docstring error only surfaced on `just check` after the format pass. Shorten docstrings to ≤ 100 columns on first write to save one cycle.
