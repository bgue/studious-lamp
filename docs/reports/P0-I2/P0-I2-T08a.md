## Learnings (proposed)
- `just check` runs `ruff format --check`, and it rejects a multi-line wrap that fits within 100 columns. Run `uv run ruff format <file>` on each touched Python file before `just check`, so the check does not fail on formatting alone.
- The ticket's Context list omits `schema/fixtures/*.yaml`, which `packages/tl-schema/tests/conftest.py` loads. The provided tests' expectations (for example the single L004 warning) depend on those fixtures. I did not read them because they are outside the Context list; the rule table plus the provided tests were enough to pass. A future ticket of this kind could list the fixtures in Context.
