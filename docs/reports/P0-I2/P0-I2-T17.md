## Learnings (proposed)
- Parametrised snapshot tests store files with brackets in the name, for example `test_status_message_in_the_footer[size0].raw`. `ls` and globs need quoting; the count of `.raw` files is 15 as expected.
- Each `.raw` SVG is a Rich SVG export that carries an `@font-face` `url(...)` pointing at a cdnjs-hosted Fira Code font. That URL is only text inside the stored file; I did not observe any network access during the test runs. Noting it in case a reviewer asks why the snapshot files reference an external host.
