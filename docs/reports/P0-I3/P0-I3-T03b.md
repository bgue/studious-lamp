## Learnings (proposed)
- The ticket's *Context* list does not include `packages/tl-core/src/tl_core/services/errors.py`, where `UnknownRelationError` and `RecordNotFoundError` live. The ticket pastes only the `RecordNotFoundError` import. I found the `UnknownRelationError` home with one grep on `links/vocabulary.py`, which imports it from `tl_core.services.errors`. Suggest: name the module of every exception the body must catch.
- `_LINKS_SQL` is a plain `str`, not a `TextClause` (`_COUNTS_SQL` is one). It must be wrapped in `text()` before `conn.execute`. The ticket says "run `_LINKS_SQL`" without saying so.
- `ruff format` does not wrap docstrings, so a docstring over 100 columns passes `ruff format` and fails `just check` (E501). Check docstring widths before running `just check`.
- Scratch placement slip (no repo effect): I first wrote a `just check` log next to the worktree and a `just test` log under `/tmp`. Both were deleted; no scratch file is committed. Use the scratchpad directory for logs.
