## Learnings (proposed)
- The Write tool refuses to overwrite or create-over a file it has not seen through the Read tool. Reading the same file with `cat` in Bash does not count. This cost one failed write. Proposed note for implementers: use Read on the stub before Write, even when the stub was already printed by Bash.
- `just test` runs `uv run pytest -q` once, yet its log shows two "snapshot report summary" blocks and two pytest summaries (1278 passed, then 1600 passed), with exit 0. I did not investigate the cause; the supervisor may want to know whether the second summary hides a second collection.
