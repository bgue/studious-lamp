## Learnings (proposed)
- SQLAlchemy `text()` on SQLite accepted a named parameter repeated six times in the counts query (`:id` in the CASE expressions and in the WHERE). No per-occurrence bind names are needed. The provided tests exercise this path.
- Python `True`/`False` bind directly to `declined` on SQLite (INTEGER, stored as 1/0) and would bind to Postgres BOOLEAN as well. No cast or conversion is needed, which keeps the INSERT and UPDATE portable.
- `ruff format` changed a wrapped call after the first write. The harness reported the file as "modified on disk" on that run. Running `ruff format` before the first test run avoids the confusion.
