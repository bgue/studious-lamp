## Learnings (proposed)
- `build_commands` skips the target only by id. A ticked record that is the target itself produces no command, so "Nothing to link" is shown and the modal stays open. This is what the spec says; no test covers it.
- The `_link` spec dismisses with `created` as soon as one link succeeds. Messages for refused links in the same batch are then discarded, and the refused records stay in the tray with no on-screen reason. See the open question below.
- The Write tool accepted the report file after one partial Read of the stub with offset and limit. No other tool quirks came up.

## Open questions / Blocked
- Partial failure: when some links are created and others are refused, the spec's `_link` dismisses with the created count, so the refusal messages are never shown. Should a partial success stay open and show the messages instead (redraw with the still-ticked refused records)? I implemented the spec as written and did not guess. The supervisor should decide.
