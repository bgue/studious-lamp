## Learnings (proposed)
- PostgreSQL sorts NULLs last for `ORDER BY ... ASC` (default `NULLS LAST` for ascending); SQLite sorts NULLs first. `_SUMMARY_SQL` (`ORDER BY t.class_code, r.status`) therefore returns the no-class line last on Postgres. The docstring "a missing class or state first" holds only on SQLite. A candidate fix belongs to the supervisor or orchestrator (see Blocked).

The three errors are at line 43, column 93, the `CreateTag(...)` call with `**more`, where `more` comes from the tuple list in `env` (lines 27–38). The likely cause is that pyright infers the value type of `more` as `str`-compatible, so `psets`, `pattern_policy` and `origin` get `str`. I have not verified the cause or a fix; the supervisor should decide.
