## Learnings (proposed)
- The parity run's count is not "28 twice". With `--adapters sqlite,postgres`, the 8 cases that do not use the `db` fixture (the malformed-command and mnemonic-case checks) run once, and the 20 database cases run on both adapters: 8 + 2 × 20 = 48. A supervisor reading "48 passed" should expect that split, not a 56.
- The STEPS line for the default sort order ("ten more than the largest sort_order, or 10 when the scope has none") is satisfied by `max((row.sort_order for row in existing), default=0) + 10`, with no special case for an empty list.
