## Learnings (proposed)
- A full `uv run pytest packages/tl-cli -q` takes about 5.5 minutes (332 s), which is over the 120 s foreground limit of the Bash tool. It has to run in the background and be polled; a foreground run is moved to the background automatically.
- The Bash tool blocks a `sleep` followed by other commands; waiting on a background task is done with an until-loop, not with chained sleeps.
- Scratch output was briefly written under `/tmp` by mistake (removed afterwards); the session scratchpad is the place for it.
