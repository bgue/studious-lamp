- `just test-parity` takes about 70 minutes on this machine (`4161.07s`). A backgrounded run with
  the default 30-minute limit is killed with SIGTERM (`recipe test-parity was terminated by signal
  15`) and leaves no summary. Start it with `run_in_background` and `timeout: 7200000`.
- The ticket's STEPS and the pasted interfaces were enough to implement the bodies. The pasted
  registry block omits the `active` property on `TagClassRow`, which `get_tag_class` depends on
  (STEPS step 2). Pasting the row properties would have saved an exploration.
- Empty-string query parameters: the STEPS say "when project is given", which does not say how
  `?project=` is treated. Worth one line in the ticket template for query-driven scopes.
