## Learnings (proposed)
- `csv.reader` returns `[]` for a blank line, so `not any(stripped)` skips it without a special case.
- The 5,000-digit `int()` test depends on the Python 3.12 int-string digit limit (4300 digits by default); `int()` raises `ValueError` there. On an older Python the test would see no problem.
- The stub file in the worktree matched the ticket's pasted interfaces exactly; no interface mismatch.
