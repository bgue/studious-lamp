## Learnings (proposed)
- A stub body that passes a `str` to a pydantic model field typed as a `Literal` (here `family: TagFamily`) fails
  pyright standard even though the model validates at runtime. The stub's STEPS (`family=family`) and its import
  list did not foresee this. Next time either pass the `TagFamily` import in the stub or run pyright on the stub
  bodies before dispatch (same class of defect as L-P1-I1-4 part 2).
- Full `uv run pytest packages/tl-cli -q` takes about 5.5 minutes; the Postgres parity run of this file about 1.2 minutes.
