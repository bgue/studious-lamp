## Learnings (proposed)
- `just test-parity` runs the full `-m "parity or requires_postgres"` set over the whole repository. Here it took 4297 s (about 72 min), which is longer than the default background limit of a `run_in_background` command. Start it with `run_in_background: true` and `timeout: 7200000`, or the run is killed at about half way.
- The ticket's `_describe` STEPS say only "return" when no tag is highlighted. That leaves `self.detail` holding the last described tag, not `None`. It was implemented as the STEPS say (see Open questions).
