## Learnings (proposed)
- A stub's `# ruff: noqa: F401` can hide an import the STEPS never use. When the ticket says to remove the `noqa` line, expect F401 on that import and remove it (this ticket: `datetime.date`).
- `registry.find_code_value` and `find_standards` callers: `find_code_value` returns `| None` even after a write that must have created the row. Under pyright `standard` the STEPS' direct attribute access needs a `None` guard. Worth a note in the ticket template for handler-style CLI tickets.
