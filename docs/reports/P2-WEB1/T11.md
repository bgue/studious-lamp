## Learnings (proposed)
- `package_text.package_page` marks the record `Id` as `panel=False`, so the terminal's panel never shows the id, even in technical mode. The twin recipe's (i) assumes it does.
- `WebLog.keep_columns()` keeps a column named `State`; the package log names it `Status`, so only the Number and the flex column (Subject) are always kept.
