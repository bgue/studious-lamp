## Learnings (proposed)
- `path_text.path_cells` and `compare_cells` return tuples; `htmlkit` rows are lists, so tests must `list()` them (cost two failing runs).
- The panel passes `previous` in every mode (the terminal does), so a version-2 panel always has a "Steps changed" section; a test expecting the bare page panel must pass `previous`.
- `ruff check` (E501) also checks docstrings; `ruff format` does not rewrap them, so keep module docstrings under 100 columns by hand.
