## Learnings (proposed)
- FastAPI 0.143 keeps included routers as `_IncludedRouter` in `app.routes`; flatten via `original_router` + `include_context.prefix`.
- The documents seeder writes to `root/"docs"` with secret `s`: an app that serves those files must use that store or the bytes are 503.
- A hidden file's 404 text names the asked id: swap ids before comparing, with never-ids of the same length.
- Starlette answers a 500 outside `add_middleware`: wrap `build_middleware_stack` for anything that must cover it.

## Fix (P2-Q10, orchestrator-approved security fix in src)
A 500 under `/web` lacked CSP, `nosniff`, `Referrer-Policy`, `Cache-Control`: `tl_api/app.py` `_internal` answers from Starlette's
outermost `ServerErrorMiddleware`, outside `WebHeadersMiddleware`. `tl_web/app.py` only: `mount` calls `_wrap_stack`, which wraps
`app.build_middleware_stack` so the middleware (the one `SECURITY_HEADERS` set) is outside every middleware and handler.
`tl_api/app.py`, non-`/web` answers and JSON error bodies unchanged. The 500 test also pins `no-store`, body and one CSP.
