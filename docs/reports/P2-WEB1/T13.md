## Learnings (proposed)
- The materials seed (T17) has no Rejected receipt, so the rejection-reason case builds one in the test (a `model_copy` of RCV-0002 served by patched reads). A seeded Rejected receipt would make that case a plain seed test.
- `ReceiptWebLog.row_open_key` returns `None` (D41); the base `WebLog._open_url` then leaves `data-open` empty, which the walk and the tests rely on.

3. `panel_text(None)` returns `["Nothing here."]` (copied from the documents model). The base `WebLog` never calls it with `None`, so this is unreachable.
