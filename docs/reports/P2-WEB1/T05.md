## Learnings (proposed)
- `S3.World.upload` hardcodes `content_type="application/pdf"`. Under the ticket's rule (type or `.pdf` name)
  a text file sent through it would get the viewer, so a text file needs its own upload with `text/plain`.
- `base.html` has no `head` block, and it is not in Allowed paths, so `viewer.css` is linked from the content block.
- `WebReadClient.file_info` returns `FileInfo` without `sha256`; the SHA-256 comes from the JSON `GET /files/{id}`.
