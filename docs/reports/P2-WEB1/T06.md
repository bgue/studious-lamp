## Learnings (proposed)
- `just check` took longer than the 120 s foreground limit here, so the call was moved to the background. A `pgrep -f "just check"` wait loop matches its own shell and never exits; wait on the PID or on a sentinel file instead.
- Package root for a manifest is taken as the nearest ancestor whose parent is named `packages`. A manifest outside that layout is reported with its full path.

## Open questions / Blocked
none. Choices the ticket left open, all in `vendored_problems`:
1. The sha256 comparison lower-cases the manifest value (hex digests are case-insensitive).
2. A file that is not found still gets the licence check; a missing file skips only the hash check.
3. A `file` array containing a non-table element counts as an unreadable manifest.
4. An `OSError` while reading a listed file is not caught; it propagates.
