## Learnings (proposed)
- `present.plain_lines` shows quantities through `qty_text`: `15.500` renders as `15.5` and `30.000` as `30`. Expect the rendered text in panel tests, not the Decimal's scale.
- The panel route's status line (out-of-band) is built from the panel request's own query, which carries only `mode`. On a filtered page (`?state=Retired` here, `?open=1` on receipts) a clicked row therefore shows the unfiltered summary. This is read from `WebLog._panel_url` and `panel_page`; it is not covered by a test. Shared with T13.
- The terminal's item rows pass no labels; the web passes `self.labels`. With the seed the cells are identical either way (asserted in case b).
