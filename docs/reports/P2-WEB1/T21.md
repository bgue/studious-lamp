## Learnings (proposed)
- `page_facts` is a looser check than the terminal line equality: it proves each fact is shown, not the layout. Use `page_facts(a) != page_facts(b)` for "differs" assertions; `missing_facts(a, b) != []` is wrong for that (a plain page's facts are a subset of the technical panel's).
- `_selected_context` never calls `panel_text(None)`; the "Nothing here." line for an empty log comes from the base class, so `panel_text(None)` overrides are dead code except for fixed lines like "No stock on hand".
- A bash `cat > file` with no heredoc waits on stdin and stalls the shell for 120 s.
- `sed -i '/start/,/end/ s/…/'` range matched inner functions in the same file; check with `git diff` after bulk sed.
