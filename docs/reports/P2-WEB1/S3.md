## Alias approach
Each tl_tui alias does `from tl_api.preview import X as _moved` then `sys.modules[__name__] = _moved`. The import system
binds `tl_tui.preview.X` to whatever is in `sys.modules` after the load, so `from tl_tui.preview import render, cache`
yields the one real module and `monkeypatch.setattr(render, "WORKER_COMMAND", ...)` acts on it. The wildcard import
(plus `_limit_resources`) is only for pyright, which cannot follow the `sys.modules` swap.

## Order in the route
open_file under the viewer -> size (`info.size`) and `%PDF-` -> cache lookup (hit: no slot) -> `RENDER_SLOTS.acquire(blocking=False)`
else 503 `preview_busy` + `Retry-After: 2` -> copy bytes (<= 50 MB + 1 guard) to a private temp dir -> `render_first_page`.
Every refusal is 404 `no_preview`, one text. The mirrors call `download_file` / `get_file_page1` with the same arguments;
errors propagate to the app's own handlers, so status and JSON body are the route's.
