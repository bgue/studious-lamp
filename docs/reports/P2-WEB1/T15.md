## Learnings (proposed)
- A `TYPE_CHECKING`-only type cannot appear in a runtime base-class subscript such as `WebLog[RfiLogLine]`; quote it (`WebLog["RfiLogLine"]`), or the recipe in `tl_web.log` fails at import.
- The S4 page hook (`S4.PAGE_SOURCE`) is a module global read by `World.__init__` at call time, so a script can swap it before building `World`.
- A secret word sent in `?q=` is echoed into the filter input. A "no secret in any answer" scan must not use the secret as the viewer's own query.
