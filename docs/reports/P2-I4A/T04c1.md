## Learnings (proposed)
- T04a's views default the viewer to `LOWEST` and ignore the ambient viewer. A route that "passes none" silently shows cleared readers the low view. Routes must pass `current_viewer()`.
- The ticket's hide pattern (`hide()` in `req_world`, which UPDATEs `for_record_id`) is a projection write. A requisition's `for_record_id` must be an IWP or CWP, so a restricted correspondence item cannot serve as its subject. Classify an IWP through a class source instead.
- The awp read routes have no word check (`guard("document.read")`). The word-check pattern is `routes/constraints.py::_view_reader`.
