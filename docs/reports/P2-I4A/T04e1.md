## Learnings (proposed)
- An approve, reject or schedule returns version +2 after the state move (raise is 2, approve is 4), not +1. Tests read the version from the output, not from arithmetic.
- The scaffold key prefix is `SCF`, not `SCA`.
- `pyright` rejects `type[Command]` as the constructor for command-specific kwargs; `Callable[..., Command]` is the working type for a shared verb helper.
- A `requires` link between a requisition and an IWP is not fixed in direction in tests; check both.
