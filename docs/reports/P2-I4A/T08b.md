## Learnings (proposed)
- MCP tool errors reach the agent prefixed `Error executing tool <name>: `; tests must match with `in` or `endswith`, not `==`.
- A command cannot make a requisition hidden by subject (the subject must be a visible IWP or CWP). Hidden-requisition tests need either a fixture that accepts a restricted subject or the projection UPDATE of `test_api_and_visibility.py`.
- The walk file asserts a candidate for every required argument, so a new tool with a required `key` needs a `key` candidate even when the ticket does not list one.
- `tl-mcp` does not declare `tl-mod-requisitions` in its dependencies (as with `tl-mod-awp`); the import resolves through the workspace. No dependency was added.
