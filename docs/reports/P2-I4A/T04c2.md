## Learnings (proposed)
- `EmbeddedClient(factory, actor=...)` takes the actor by keyword. `support.build_pair` hard-codes the token actor, so a test that needs another actor has to build its own pair.
- The roundtrip test checks parameter names and defaults only, not annotations. Adding a `ClientInterface` method therefore only needs the ApiClient and the embedded client to carry it.
