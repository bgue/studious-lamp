## Learnings (proposed)
- `WorkOrderRow.hours_planned` and `hours_actual` are text (`"48"`), not Decimal. A screen must convert them before `hours_text`.
- The work order state filter cycle uses the state values `Open`, `Scheduled`, `Assigned`, `Started`, `Completed`, `Closed`. `tl_mod_requisitions.names` names only `ST_OPEN` and `ST_SCHEDULED` as state constants; the others exist only as `WorkOrder.*` event names.
