## Learnings (proposed)
- The ticket's *Interfaces* block line numbers are the ticket file's, not the source file's: the
  pasted `commercial_flow.py` starts at line 47 of the ticket. When matching an old string
  against the repository file, take the text from `sed -n` on the file on disk, not from a view of
  the ticket. My first `Edit` attempt used text I had copied from the ticket view and failed
  safely with "String to replace not found"; no file change resulted.
- `uv run ruff format <file>` reports "1 file reformatted" on the first run after a hand edit, and
  the edit tool then warns that the file changed on disk. This is expected and was not a conflict.
- The `--adapters sqlite,postgres` run of this file took about two minutes with `TL_PG_URL` set
  by the session hook; the package suite took under two minutes. The 600000 ms timeout was enough.
