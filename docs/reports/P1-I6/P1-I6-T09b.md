The same tree passed on a second `just check`, and `uv run pyright` alone reported 0 errors. Treat a bare exit 247 from pyright as a possible transient and rerun once before reading it as a type error.
- The ticket file path in the task text was doubled (`<worktree>//home/user/wt/p1-i6/...`). The worktree's own copy at `docs/tickets/P1-I6/` existed and matched, so the harness path should be built from the worktree root.
- STEPS 8 writes `_amount(...) or Decimal(0)`. `Decimal(0)` is falsy, so `or` falls through to a zero of the same value. The result is correct; no reader needs to change it.
