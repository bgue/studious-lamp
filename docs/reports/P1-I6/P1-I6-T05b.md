## Learnings (proposed)
- The ticket's STEPS and its pasted `PlannedCommand` interface disagree on length: a `MAX_TEXT` (500) title can exceed `PlannedCommand.summary` (300) once a prefix is added. Either the STEPS should say "truncate the summary" or `MAX_TEXT` for the subject should be checked against the summary limit when a summary is built from a title.
- A stub's header text ("delete this paragraph ... when written") is outside the "edit only the function" rule of the ticket. Tickets that want header cleanup should say so explicitly.
