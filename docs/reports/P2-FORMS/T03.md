## Learnings (proposed)
- `v_forms_*` return NULL `status` for a draft or a template; a reader must coalesce to the first state, as requisitions does. The ticket does not say so.
- Templates carry keys, so "a draft has no key" applies to submissions only.
- `World.template` fixes the title, so tests that need distinct titles call `world.call("ada", "DraftFormTemplate", ...)`.
