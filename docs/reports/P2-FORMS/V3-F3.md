# V3-F3 report: web fill page, card links, demo clause 9

**For the owner (plain English, 5 lines)**
1. A signed-in person can open `/web/forms` in a phone or desktop browser, pick a form, fill it, save a draft and come back to it, and send it; they get a "Received P200-FRM-0016" page.
2. From an inspection's scan card the person follows "Open record", fills the inspection's checklist in the browser, and the inspection becomes Done through the inspection's own command, as if recorded in the terminal.
3. The browser only helps: the server checks every answer again, the typed command's own permission still decides, and a refused form shows one `!` line and never repeats what was typed.
4. A record you may not see, a form that does not exist and someone else's draft all show the same "Not found" page, byte for byte; agents get no web session at all. Five kinds of reader are tested, and the page runs under the unchanged strict security policy (no inline script, no violation seen in a real browser).
5. Template text is shown as plain text: a template whose question is `<img onerror=...>` or `</script>` makes no element and cannot end the data block (tested with the parser and in Chromium).
