# V3-P0 report: `tl report <module>`
Deviations: `scaffold_list` gained `offset` (default 0) to page; RFI log and document register have no offset (read once, bound 1,000,000); awp and materials reports register from `tl_cli` (they need cost codes); no technical-details flag (no report has an id column).
Modules (17 reports): form-submissions, form-templates; rfis, correspondence; documents; scaffolds; awp-{cwp-status,wbs-vs-cost-code,cwa-sequence,iwp-status,iwp-readiness,constraint-log}; materials-{stock-on-hand,movement-log,mto-status,shortages,consumables-by-cost-code}.
Left out: awp KPI tiles and grouped counts (totals), materials heat_trace (needs a heat). Existing `tl corr|doc|tag|awp|mat report` untouched.
Headers: forms `key,state,template,template_version,subject,answer_class,author,submitted_on,reviewed_by,reviewed_on`; RFIs `number,subtype,state,discipline,raised_on,issued_on,required_by,answered_on,response_days,on_time,overdue,days_overdue,...,class,subject`; documents `number,state,doc_type,discipline,current_revision,current_status,current_class,current_issued_on,revisions,open_revision,stale_links,title`.
Tests: 5 hook and writer (`packages/tl-core/tests/test_report_hook.py`); 25 in-process (`tests/confidentiality/test_reports_v3.py`: headers, counts equal list view for 3 viewers, hidden == missing byte-identical to a ledger where the record never existed, JSONL == CSV, command); 33 on a generated ledger (`tests/reports/test_demo_reports.py`: header, count == list view, JSONL == CSV, restricted document and RFI absent for low with all other rows unchanged; builds in ~3 min, `TL_REPORT_DEMO_DB` reuses one).
Not covered: scaffold, awp, materials have no restricted record in the generated ledger (their hidden == missing rests on the unchanged views); templates are not confidential (pinned by a test).
Mutants: sentinel (drop header), formula quote, duplicate-name check, forms read as lowest viewer: all killed.
Open: (1) reports filter by class only, like the other `tl ... report` commands; the scaffold API route also needs `scaffold.view`; enforce module view words? (2) report calls are slow on big ledgers until V3-P1 lands.
