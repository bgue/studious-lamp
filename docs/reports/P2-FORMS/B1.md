## Learnings (proposed)
- `just check` runs whole-repo pyright last; on a 15 GB box with other work running it is SIGKILLed (exit 247) and the error text does not say memory. Scoped pyright is the usable check for a ticket.
- Test helpers that build format 1 keys produce ids like `hours` that format 1 refuses (`^q[0-9]+$`); pass `fmt=2` for named ids.
