## Learnings (proposed)
- Pyright exit 247 with no output is the kernel OOM killer (cgroup), not a type error. Check `dmesg` for `Memory cgroup out of memory` before reading it as a failed type check.
- Several worktrees on one host running full pyright at once starve each other, so a gate run can fail for reasons unrelated to the branch.
