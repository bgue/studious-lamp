## Learnings
- Under parallel worktrees, `uv run pyright` over the whole repo can be SIGKILLed (exit 247) with no message. Retrying later or running pyright per package works.
- `rules.visible_ids` ignores answers whose value is None, so a None value on a field also hides fields that depend on it.
  The runner relies on this when pruning.
- Ruff E501 applies to the module docstring line; keep the first docstring line under 100 characters.
