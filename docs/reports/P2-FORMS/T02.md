## Learnings (proposed)
- The bash tool runs in a memory cgroup. A whole-repo pyright (about 2 GB RSS) is OOM-killed under `just check` (exit 247, no message). The same command run directly passed. Check `dmesg` for `oom-killer` before treating 247 as a code failure.
- `rules.visible_ids` ignores answers whose value is None, so a None value on a field also hides the fields that depend on it. The runner relies on this when pruning.
- Ruff E501 applies to the module docstring line; keep the first docstring line under 100 characters.
