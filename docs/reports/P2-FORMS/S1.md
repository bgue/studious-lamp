## Rules the specs left open (my choice, all tested or harmless)
- `unit`, `min`, `max` are type-checked only when non-null, on any kind; not forced null on other kinds.
- An answer with value null is a problem (not "unanswered"); `note` may be absent.
- `FormBinding` defaults: `template`, `reason`, `command`, `answers_arg`, `expected_version` None; `fixed_args` {}; `prefill` [].
- `visible_when` problem for a depth over 3 is reported once, on the top node.
- Problems for a missing key: `<label>: missing key 'x'`; empty list: `question list: ...` (no label).
