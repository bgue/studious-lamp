## Learnings (proposed)
- `ruff format` does not split an over-long f-string: it left a 102-column string literal in `reviews.py`, and only `ruff check` (E501) caught it. Split such strings by hand before committing.
- `just check` output contains carriage returns (pyright progress line), so `grep` reports "binary file matches" on the saved output. Use `tr '\r' '\n' < file | grep -a ...` to extract the decisive lines.
