## Learnings (proposed)
- The `Edit` tool refuses to change a file that was only pasted into the ticket; the first batch of five edits failed with "File has not been read yet" even though the stub text was in the ticket. Reading the file in the session before editing fixed it. A ticket that says "edit the stub" should tell the implementer to read the stub first.
- The `_fill` STEPS say "compared in lower case" in a sentence that lists state and doc_type as well as the text needle. I applied the lower-casing only to the number/title match and kept state and doc_type as exact equality, since `next_choice` reads the stored values as they are. The tests pass either way; the ticket could say which comparison is meant.
