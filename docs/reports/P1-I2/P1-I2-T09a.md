## Learnings (proposed)
- The ticket's STEPS `fields = {name: (value or None) ...}` works only because `handle_update_document` reads `cmd.model_fields_set`: an explicit `None` counts as "given" and clears the field. A reader who "simplifies" the dict to drop `None` values would break the empty-value-clears behaviour. Worth a line in the ticket template or LEARNINGS for `update`-style commands.
- `uv run pytest packages/tl-cli -q` takes about 6m40s on this machine (623 passed). The ticket gives no time estimate for this command; budgeting for it avoids a false "hung" reading.
