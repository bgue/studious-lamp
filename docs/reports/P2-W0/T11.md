## Learnings (proposed)
- `proposals.submit` runs the handler's precheck as the agent. An agent with no documents module role gets `forbidden: SetPsetValues needs the user access word for documents on project:P1` at proposal time, before any person decides. `propose_import_impl` (`tl_mcp/derivation_tools.py`) uses `submit`, so this may be intended or a gap. Worth a supervisor look.
- A publication accept is gated on the account role (`Principal.is_controller`), not the module grant. The API docstring says "document controller or admin", so this matches the text, but a reader may expect a superuser grant to be enough.
- A process that publishes a derived document must call `derivation_store.configure(FileService(...))`; otherwise the accept fails with `DerivationNotConfiguredError`.
- The tag plan does not check the tag class; `tl load load` fails with `no active tag class 'ControlValve'` until the company standards are loaded.
