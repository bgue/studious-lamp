## Learnings (proposed)
- `proposals.submit` runs the handler's precheck as the agent, so an agent with no documents module role gets `forbidden: SetPsetValues needs the user access word` at proposal time. `propose_import_impl` (`tl_mcp/derivation_tools.py`) uses `submit`: intended or a gap, worth a supervisor look.
- A publication accept is gated on the account role (`Principal.is_controller`), not the module grant. The API docstring says "document controller or admin", so this matches the text, but a superuser grant is not enough.
- A process that publishes a derived document must call `derivation_store.configure(FileService(...))`, else `DerivationNotConfiguredError`. The tag load needs the standards loaded (`no active tag class 'ControlValve'`).
