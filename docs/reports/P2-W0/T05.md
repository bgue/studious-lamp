## Learnings (proposed)
- `DisplayMode` takes no constructor arguments; a ticket that writes `DisplayMode(technical=True)` fails with `TypeError`. Set `.technical` on an instance.
- `details._RENDERERS` fills on the first `details_for` call (`_load_renderers`); a script that reads it first must call that function.
- `documents.Document` has a renderer, so the first draft_only type without one is `documents.Rendition`. A ticket example that names `Document` as a no-renderer draft_only type would not match the table.
- `ruff` B007 flags an unused loop variable in acceptance scripts, and E501 fires on long check labels; both showed up in `just check`.
