## Learnings (proposed)
- The brief's own caps (BOARD 15 plus marker, LOG 10) take 28 of the 40 lines, so a populated WT/HEADS section pushes NEXT out of a 40-line output. Either the cap on BOARD is lowered, or NEXT is printed before WT and HEADS.
- A "trunk" fallback needs a named ref. `main` is an ancestor of this repository's trunk, not the same commit, so "main is the trunk" is not a safe assumption for a script.
- A STATE.md NEXT line over 160 characters is cut by the script. Either the STATE author keeps lines short, or the spec says so.
- `git status --porcelain` counts untracked files, so a worktree with only a new file reads as dirty.
