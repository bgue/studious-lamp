## Learnings (proposed)
- `grep -c '^[A-Z]*$'` also matches an `OK` line, so the acceptance count of six section names is wrong whenever PATHS is clean. Count the known section names instead.
- Under `set -o pipefail`, `cmd | head -n N` can fail on SIGPIPE; use `awk 'NR<=N'` (reads all input) instead.
- `read -r -d '' VAR <<'AWK' || true` keeps awk programs in readable heredocs under `set -e`.
- This ticket's own Tests-to-add bullet has a `a` -> `b` example in prose; the script reads it as a real mapping. Keep mapping examples out of bullets.
