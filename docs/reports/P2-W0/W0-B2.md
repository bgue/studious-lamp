## Open questions / Blocked
- `MappingTarget` writes `create_module_record` (envelope event only): fields `title` and `description`; no psets.
  It fits record types a module projects from `Record.Created` alone; a type with its own events needs a handler class.
  Compensation appends `Record.Voided` on the record's own stream, like the module void handlers.
- A company run opened with `--company` has no `--company` on `extract` .. `show` (they take `--project`); the spec
  names `open` only. A company target cannot be advanced from the CLI until a follow-up adds it to those commands.
- A module publish target registered by entry point still cannot be chosen by a derived document: the schema's
  `target_kind` (a `Literal` in `schemas.py`), `names.TARGET_KINDS` and the generated mapping-format JSON schema
  (`schema/**`) name `tags`/`documents` only. That is a schema change, not made here.
- `docs/modules/legacy/README.md` still says the target is `tags` or `documents` (outside Allowed paths).
