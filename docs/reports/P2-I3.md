# P2-I3 report: M4 materials

Status: done (C4). Branch `p2/i3`, merged into trunk by the orchestrator on the integrated wave branch `p2/wave1-close`.

## Objective
Add the materials module (brief M4): an item library, locations, receipts with mill test reports, stock movements,
reservations against take-off lines, and a published MTO, usable from the CLI, TUI, API, MCP and the simulator.

## What shipped
- Item library (ItemMaster, ProjectItem) with closed code lists; location tree (depth-limited, no re-parenting).
- Receipts (draft, inspected, accepted, rejected, void) with gap-free RCPT numbers and an MTR file slot; accept needs the MTR.
- Movements as stock-lot events per ADR-0022 (receive, issue, transfer, return, adjust, scrap); `cur_materials_stock` keeps a stored `available`.
- Reservations against MTO lines; MTO publish target `mto` (PublishDerivedMto, AssignMtoLines) on generic documents extension points (D22).
- Readiness check `materials_reserved`; six reports with CSV; nine GET routes plus two (S5), all through the viewer.
- Six TUI screens on keys S Stock, M Movements, E Receipts, D MTO lines, I Items, W Locations (T13), plus palette entries and an MTR upload on receipt entry (T06j).
- Ten MCP tools: nine reads and `propose_reservation` (T07); agents are denied every materials command.
- Simulator: `MaterialsDesk` and the `materials_coordinator` actor (T12). Loaders `mat-*` and `tl load --company` (T01b, T08a).
- Docs: package README and AGENTS.md, runbook `docs/runbooks/materials.md` (T10).
