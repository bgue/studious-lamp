## Learnings (proposed)
- Command models built without an envelope fail validation. Pass `**ENVELOPE` to the constructor, then `stamp`; the attempt catches the `ValidationError` and it reads as a refusal, so a missing envelope looks like "nothing sent".
- A cleared constraint leaves the Open and Assigned reads, so a `waived` state cell can only show if a read returns the cleared row.
