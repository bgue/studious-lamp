## Learnings (proposed)
- Command models built without an envelope fail validation. Pass `**ENVELOPE` to the constructor, then `stamp`; the attempt catches the `ValidationError` and it reads as a refusal, so a missing envelope looks like "nothing sent".
- A cleared constraint leaves the Open and Assigned reads. The waived state only shows when a third read (Cleared) returns it.
- A list read has no sign-off count (`IwpRow`, `IwpCountRow`); the count is `len(IwpDetail.signoffs)` from `get_iwp`. A per-row read belongs in the panel of the highlighted row, not in each list cell.
