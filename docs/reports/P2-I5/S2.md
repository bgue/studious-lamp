4. A recorded figure keeps its edition: with a stored row `earned_fraction` and the handlers use the row's edition, not the setting. A package with no

   figure, edition or manual list changed; `CompleteIwpField` always writes one, last. The `ProgressRecorded.at` is now (UTC).
7. `ReturnScopeItem`/`VerifyScopeItem`/`InstallScopeItem` need `expected_version` of the scope item; `RecordManualProgress` of the IWP. Field is `steps` (list of `scope_item_id`, `step`, `done`).
8. `record_state:<type>:<State>`: a type is "known" when a record of that type exists; known types are earned when a record linked to the item is in that state; unknown skipped, note `type not recorded yet` (once).
9. Handlers never read `intent` (ADR-0025). Agents only propose: `propose_progress` and `propose_scope_installed` (`ProposableCommand`, access `user`); acceptance by a person without `awp.progress.record` raises `ProposalAccessError` (checked in `S2.py`).
