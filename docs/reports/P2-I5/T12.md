## Learnings (proposed)
- `tl constraint raise --phase` must name a guard phase of the workflow; for an IWP the phase of an unnamed guard is the transition name (`start`), not `issued`.
- `constraint` state is `cur_core_record.status` (`COALESCE(status, 'Open')`); `cur_core_constraint` has no state column.
- `awp iwp release-hold` moves to Constraint check, not Issued; `week commit` needs `--hours`.
