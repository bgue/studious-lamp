## Learnings (proposed)
- `LogScreen` hides a column whose value is the same on every shown row (`keep_columns` only keeps the constant ones). So `Ready`/`Blocking`/`Since` disappear from the table when all shown rows agree. Tests that need those cells read `row_cells`, not the table.
- `humanize` lowercases the actor in the summary (`foreman sue`), so the summary text is not the actor's display name.
- `ruff format` runs on new files before `just check`; the format gate is separate from ruff check.
