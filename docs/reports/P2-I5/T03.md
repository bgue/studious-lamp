## Learnings (proposed)
- `iwp_list` defaults to `limit=200`; the ticket asks for 500, so it must be passed explicitly.
- `list_constraints(limit=...)` counts across the whole scope, so a list cannot give a complete per-IWP figure;
  use `count_constraints` with `subject_id` for any per-subject total.
- The first `just check` failure on `p2/i5` was a single ruff E501 line; the merge fixed it. A report that
  says "not green" can be stale after the branch moves, so re-run after merging.
