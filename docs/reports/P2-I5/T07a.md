## Learnings (proposed)
- The file service dedupes identical bytes: a second `--attach` with the same content keeps the old file id
  and adds no revision. A replacement test must change the content.
- `PinIwpDocument` accepts only issued revision codes; an unissued code is refused with ScopeRuleError.
- The awp `iwp_views` reads take no viewer; they use the context viewer, so `build_pack_data` wraps reads in `cf.use_viewer`.
- The ticket's trailer named a different model than this session runs as; I used the session's own model line.
