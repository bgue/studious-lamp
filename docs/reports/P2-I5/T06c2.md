## Learnings (proposed)
- `ClientInterface.get_setting(user=...)` takes the bare user id; the `actor` string is `user:<id>`. Use `tl_tui.settings_text.user_of(actor)`. The ticket's `user=actor` would silently read no user layer.
- `tui.landing` has scopes `platform, user` only, so a "company-set" test cannot be seeded through the fake.
