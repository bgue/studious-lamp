## Learnings (proposed)
- FastAPI does not reject duplicate `operation_id`s. Only `test_openapi.py` catches them. A new route should grep `operation_id=` across `routes/` first.
- The all-routes confidentiality walk needs a candidate for every new path parameter, so a new `{param}` route fails the gate until someone edits `candidates()`.
- `ProgressWorld` plus `WeekWorld` on the API harness: `seed_awp` returns the `World`, and `progress_world` is loaded by path after `awp_world`, as `test_api_awp` does.
