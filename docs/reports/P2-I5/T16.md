## Learnings (proposed)
- A reference ledger in a second DB must run with the walk's class sources off. A source with no class-table row hides the record, so a reference without the table fails or hides everything.
- An MCP `call_tool` result dumps as `{content, structured_content}`. Compare the `structured_content`. `content` repeats `as_of_seq` as text.
- `as_of_seq` (the ledger head) differs between two ledgers by construction, so any reference comparison must drop it.
