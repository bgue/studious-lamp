## Learnings (proposed)
- `FakeClient.get_record` answers None for an IWP unless a test calls `add_stored_record`; `seed_iwp` does not add records. The screen raises `RecordNotFoundError` in that case (shown on the status line). Worth seeding the record in the awp fixtures.
- A `LogScreen` action key is checked only for offered row actions (`on_key`). A screen-level key that must work with no rows needs a `Binding`, and binding keys are reserved from row actions.
- `Literal` outcome types matter: the pyright pass caught a `str` passed to `RecordWeekOutcome.outcome`.
