## Learnings (proposed)
- A test that calls `_worker.main` in-process sets RLIMIT_CPU on the pytest process: the first gate run died with SIGKILL (exit 137) at 10 s of CPU. Patch `_limit_resources` in such tests.
- `.pyc` caching hides a same-length mutant (`{64}` -> `{63}`) written within one second: clear `__pycache__` between mutants.
- A `# pyright: ignore` comment mid-expression silently turns the rest of the line into comment.
