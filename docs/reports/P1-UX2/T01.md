## Learnings (proposed)
- `just check` runs ruff with a 100-column limit that also applies to docstrings, so a one-line docstring with a section sign and a long summary can fail lint.
- Pyright strict infers `dict` literal values as `str`, so a dict lookup used as a `Literal` return fails `reportReturnType`. An explicit `if` chain that returns literals avoids the problem.
