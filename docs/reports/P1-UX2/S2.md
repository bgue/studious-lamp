## Deviations
- `LogScreen` is declared `class LogScreen[Row](ModalScreen[None])` (PEP 695), not `Generic[Row]`: ruff UP046 fails
  `just check` on the `Generic` form. Same typing meaning.
- Extra public helpers beyond the spec: `LogScreen.say`, `attempt`, `reload`, `current`; `check_action_keys`,
  `usable_actions`; `log_text.key_label`, `ActionLike`; `ChoiceField`. `attempt` is how a form callback sends a command
  and gets the same "! " refusal handling.
- Key collisions: offered keys are per row, so the check runs when a row's actions arrive (not in `on_mount`). Headless
  (test) run raises `ValueError` (surfaces as `WorkerFailed`); a real run drops the offending action. Reserved keys also
  include the host screen's own bindings.
- Summary line shares `#log-status` with refusals (a refusal shows until the next reload/filter/summary write).
- A failed actions read gives a fully empty bar (not even "[Enter] Open record"), as "empty bar" reads.
- Field widget ids in `ActionFormScreen` are `field-<name>` (`#form-reason` is the message line).
