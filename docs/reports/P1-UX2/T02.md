## Learnings (proposed)
- `just check` runs ruff with a 100-column limit that also applies to docstrings; keep one-line docstrings short or the check fails even when the tests pass.
- `file_kind` rule wording: the ticket says only `application/octet-stream` or empty content types fall through to the extension. I read other unrecognised content types as terminal (`File`), so `application/zip` with `x.pdf` gives `File`. The provided tests do not cover this case.

## Open questions / Blocked
- None blocking. Two points for the supervisor to confirm:
  1. Unknown non-empty content type with a known extension (e.g. `application/zip`, `x.pdf`): implemented as `File` (literal reading of the fall-through sentence). If the intent is extension fallback for any unrecognised type, this is a one-line change.
  2. Rounding edge: `1048575` bytes renders as `1024.0 KB` (value just under the 1024 threshold rounds up). The ticket does not specify this case; left as the plain threshold rule.
