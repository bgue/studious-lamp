## Learnings (proposed)
- `documents.ProcessingJob` keys are `JOB-` + `new_ulid()` (`derivation/derived.py`, `_queue_job`). Any section that runs an extraction breaks determinism of the ledger's key set. `tests/tools/test_demo_project.py` runs every section, so it will fail the same way once this section is merged (not run here; inferred from the failure above).
- `DocumentsWorld` and `World` differ: `World.upload` has no `by_module`, so a receipt's `mtr` slot needs the file service called with `by_module=True` (as the materials acceptance does).
- `World` has no `refused()`; the S3 acceptance `World` does.
- The extractor is `tl_extract` (entry point `throughline.extractors`, name `tabular`); `build_worker(target, files).runner.run_until_idle()` drains the job.
- Cost codes come only from `ImportCostSnapshot` (admin); there is no define-cost-code command.

I recommend option 1 or option 3 with approval. The rest of the ticket is done. The awp package assignment is left for T01 (the code assigns automatically when CWP or IWP keys exist).
