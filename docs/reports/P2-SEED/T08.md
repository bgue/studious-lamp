- The Context list omits `data/awp/standards.yaml`, yet the general requisition type code list must live in it.

  standard but differ in code lists.
- `just gate` stops at the first failing part, so a failure in the seed is reported only after the earlier part.
- A branch cut from an older `p2/seed` shows the later commits of the base as reverted in `git diff p2/seed`.
  Check the base before reading that diff as the ticket's change.
