## Learnings (proposed)
- `--sections core,awp` fails with `the discipline is not a value of the code list Discipline`: a section depends on records of earlier sections, not only on installed record types. The registry's `needs` tuple does not express that, so a subset build can fail hard instead of skipping. The runbook says to keep the earlier sections; the supervisor may want the skip check or the docs to say this.
- `just demo-project` passes all flags through to the module, so `--seed` and `--sections` work after the path argument.
- Running `uv run python -m dev.seed.demo_project` directly, without `TL_ENV=dev`, fails with `TL_OBJECT_SECRET is not set`. The `just demo-project` recipe sets `TL_ENV=dev` (justfile line 6), so the runbook tells people to use the recipe. The direct TUI command in the runbook sets `TL_ENV=dev` for the same reason.
