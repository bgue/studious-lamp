## Learnings
- `Random(seed)` does not reproduce section draws; the generator uses `section_rng(seed, section)`. A collision check with the wrong rng misses the 1027 collision for seed 2026.
- A restricted document cannot be written by the default writer after registration (`workflow._load` returns "no record"). Set restriction last.
- `ruff check` (E501, 100 columns) is stricter than `ruff format`; run both on touched files.
