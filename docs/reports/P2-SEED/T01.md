## Learnings (proposed)
- `CommandResult.version` is the event-stream version, not the record's version. `MoveCwaInPath.expected_version` must equal the path's `current_version` (1 after define); passing the define result's `version` raises `StaleVersionError` at seed time.
- The company standards file (`dev/seed/demo_project/data/standards.yaml`) has Discipline, Area, DocumentType only. Any section that calls a PathReason or Commodity list needs its own standards file loaded first.
- Cost codes for WBS mapping come from the cost module's `ImportCostSnapshot` (no cost code list in standards); `CostRow(code, description)` with no figures is accepted.
