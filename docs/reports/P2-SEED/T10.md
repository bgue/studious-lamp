## Learnings (proposed)
- A Draft workflow record has no `cur_core_record.status` row; read the state as `coalesce(status, 'Draft')`, as `release.py` does for Ready.
- The awp week handler moves Draft to Committed on the first commit (`workflow awp-weekly-plan.yaml`: commit from Draft). A Draft plan therefore never holds a commitment.
- The `user` word for the weekly plan is held by the project engineer (awp superuser). The plan, commit and outcome use `lhartmann`; the close uses `mokafor`.
