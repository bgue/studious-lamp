## Learnings (proposed)
- A Draft workflow record has no `cur_core_record.status` row; read the state as `coalesce(status, 'Draft')`, as `release.py` does for Ready.
- The awp week handler moves Draft to Committed on the first commit (`workflow awp-weekly-plan.yaml`: commit from Draft). A Draft plan therefore never holds a commitment, so "Draft with commitments" cannot be met as written.
- The ticket calls `weekly.py` a stub, but the branch already held an implementation from attempt 1. Check `git log` on the branch before starting a ticket.
