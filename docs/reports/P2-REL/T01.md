## Learnings (proposed)
- After a `pyproject.toml` version bump, `uv run` keeps reporting the old version from the editable install's metadata until `uv sync --all-packages` is run again. A `--version` check right after the bump is misleading without that sync.
- `just check` (ruff E501) catches a long docstring that `just gate` does not; run `just check` before the gate.
