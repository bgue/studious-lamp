## Learnings (proposed)
- PyPI has an unrelated package `tl-cli` (0.2). Any `uv pip install --find-links <dir> tl-cli` without a pin resolves to it. Pin workspace names to the release version, or use `--no-index` for the tl_* wheels.
- `tl awp package ls` takes `--project`, not a positional argument; `tl awp` read commands are in `packages/tl-cli/src/tl_cli/awp_read.py`.
- uv warns that `UV_NATIVE_TLS` is deprecated (use `UV_SYSTEM_CERTS`). The smoke script passes the variable through only if set; the warning is harmless.
