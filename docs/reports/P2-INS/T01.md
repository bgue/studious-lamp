## Learnings (proposed)
- `ActivityRow.decided_by` is filled from the event payload key `by` (`insights/activity.py::_decided_by`), not from the event actor. Read it from the row, not the event, when naming a decider.
- `display.actor_label` returns `agent:<id>` raw. A table that shows `Agent: <name>` needs its own rule for agents, as done in `who_text`.
