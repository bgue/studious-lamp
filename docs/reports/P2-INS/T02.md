## Learnings (proposed)
- `DataTable` binds Enter (`select_cursor`), so a container's Enter binding never fires while the table has focus; handle `DataTable.RowSelected`.
- `FakeClient.activity` records only the method name in `calls`; a test that needs kwargs wraps the method on the instance.
- `just check` pyright can exhaust Node's default heap in this environment; `NODE_OPTIONS=--max-old-space-size=8192` makes it pass.
