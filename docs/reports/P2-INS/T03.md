## Learnings (proposed)
- Focus after a tab switch: `TabbedContent.active` alone leaves focus where it was. The fix that works is `call_after_refresh(widget.focus)`, the same pattern FilePanel uses (verified by the mutation check).
- Textual `Static.content` returns the `Text` object, so a test can read highlighted spans (`style == "reverse"`) directly.
- `(... ) &` in a shell wrapper returns at once, so a "completed" notice for it does not mean the gate finished. Read `.gate/summary.txt` for `GATE_EXIT`.
- A ticket that adds bindings should say whether each needs a keymap row. Here the help screen now omits Up and Down.
