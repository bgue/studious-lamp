## Lesson: a stricter rule moves tests you do not own
S1 changed a default (an agent files only on an explicit grant). The ticket paths covered the check; the fixtures, demos, sim and
scripts that file as an agent sat outside them. The fallout surfaced only at the DONE gate and cost five late tickets (T07 to
T11). Next time, grep the callers of the changed rule at planning time and size the fallout as a builder piece per area.

## Learnings
Appended to `docs/memory/LEARNINGS.md` as L-P2-X2-1 to L-P2-X2-4: explicit grant replaces derived roles; the DONE gate runs per
directory on 16 GB; provided tests lint where they land; admin-only streams never reach webhooks.
