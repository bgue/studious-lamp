## Choices (the spec's decisions, as built)
- Existing check only via `common.resolve_code` (hidden = absent). A code held by another record type surfaces at
  apply as the handler's `DuplicateCodeError`, re-raised as `LoadRefusedError` ("plan the run again").
- WBS: apply sorts by (depth, line). A row with `cost_codes` that is a parent of a new row is invalid (leaf-only);
  its children follow as "parent is not valid". A parent with cost codes or package allocations: "parent takes no child".
- CWA: a blank `sequence` is a CWA only. The path is a `PlannedRow` keyed `P123-POC` (so its id is a run record),
  planned only when no sequenced row is invalid; a project with a path counts it `existing`; > 500 steps or a retired
  area on the path gives one invalid line and no path.
- Reversals: WBS irreversible when changed after the load, a non-void CWP allocates, or a live child the run did not
  create hangs under it. The path is always irreversible, so `LoadService.compensate` refuses a run that defined one.
- Compare: WBS title, parent code, cost lines (when those columns exist); CWA title.
