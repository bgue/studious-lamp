- Every other value is `Label: value`: Forecast, Actual, Source system are. The CWP numbers are a bare list under their heading (a judgement call; the ticket asked for a list of numbers).
- Sections named, ordered, one blank line apart: Dates, Source, CWPs (n); `rows_page` and `render` do the spacing.
- Everyday and technical tiers apart: the record id is technical only (plain mode test asserts absence).
- Log columns: Number and Subject first; Type is third and Status fourth because the ticket fixed that order. The checklist puts State third; see open questions.

- Summary line under state: yes, in the panel only.
- Empty values: `—` in Dates and Source; `No CWPs require it` as the open-list note.
- Same labels as other screens of the same type: taken from the ticket; not compared with another screen.
- Works at 80 and 170: both mounts pass with no line wider than the width. Subject truncation at 80 was not inspected.
