## Deviations
- `register` adds `report` inside a nameless sub-app: a bare Typer app with one command collapses to it, so
  `report cwp_status` failed (exit 2). The command is still one `report` with NAME and `--csv`.
- `report` takes its own `--db` (the acceptance passes it; the root `--db` is absent on a bare app). Without it,
  the root's `ctx.obj` is used.
- Public names beyond the pasted interface: `StatusRow`, `CostRow`, `SequenceRow` (the ticket's tuples, named),
  `format_value`, `STATE_ORDER`, `UNALLOCATED`, `TOTAL`, `NONE_TEXT`, `UNSTATED`. The pasted signatures are verbatim.
- Ticket silent, so chosen here: `wbs_vs_cost_code` lists the union of awp and cost-module codes; difference is
  awp minus cost-system budget; Unallocated shows `—` for cost and difference.

## Learnings (proposed)
- Typer collapses a one-command app to that command; a test calling `<name> <arg>` on a bare app needs a sub-app.
- Pyright rejects `list[BaseModel]` for a `list[Sub]` value; annotate `Sequence[BaseModel]`.
- The ticket's Context omits `derive_support.py` (`Project`, `fail`, `cell`), `dev/accept/P2-I1/S4.py` and `S5.py`
  (the acceptance pattern); I read them for signatures only.
- The S4 seed states no `hours_budget`, so every cost figure is `—` there; the difference path is untested on it.
