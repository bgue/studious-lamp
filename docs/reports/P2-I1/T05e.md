## Learnings (proposed)
- `seed_awp` already holds one retired area (A2), so the ticket's "add a retired CWA" was unnecessary.
- A `pkill -f "just check"` attempt to stop a background run was denied by the permission classifier. Nothing was killed; the background run had already exited (its log shows the ruff failure). Use a single foreground `just check` with a timeout.
- `RecordNotFoundError` from `get_path` is the only signal used for "no path yet"; the screen then shows positions as `—` instead of an error.
