## Deviations
1. Acceptance literal changed: `cwp allocate --wbs 1.1:60 --wbs 1.2:40` is refused by the handler (`only a leaf WBS node takes a package allocation`); 1.1 and 1.2 are parents in the seed. `T04c.py` uses leaves `1.1.1:60 1.2.1:40`. Supervisor to confirm.
2. `register` reuses the `cwp` and `package` groups `awp_read.register` added. Typer replaces a same-name sub-group, which would hide the reads. Mount `awp_write.register` after `awp_read.register`.
3. Choices the ticket did not state: `move ACTION --reason` on an action without a reason is `error: ACTION takes no --reason`; `package record --type` is a Typer Choice (exit 2); a missing `--reason` on void is a Typer usage error (exit 2); an unknown package is `error: no package 'N' in project P`.
4. `T04c.py` runs `CliRunner` with `TL_ENV=dev` and a temp `TL_SESSION_FILE`; without it `--actor user:sue` is refused (`not signed in`).
