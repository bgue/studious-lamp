## Learnings (proposed)
- `.accept/` is not ignored by git (only `*.db` is). Any log written there shows as untracked; keep logs in the scratchpad.
- The route builds `TimelineRow` inline and only `_note` is module-level, so every embedded copy of `get_cwp` repeats the timeline loop. A shared `timeline_rows(events)` in `routes/awp.py` would remove it.
- `tl-tui` uses `tl_mod_awp` without declaring it; a ticket that names the import should also name the pyproject line.
- A `# fmt: skip` on the closing line of a multi-line call does not stop `ruff format`; reformat the file instead.
