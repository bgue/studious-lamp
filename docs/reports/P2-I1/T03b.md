## Learnings (proposed)
- `.accept/` is not ignored by git (only `*.db` is). Logs written there show as untracked; keep them in the scratchpad.
- The route builds `TimelineRow` inline and only `_note` is module-level, so every embedded `get_cwp` repeats the timeline loop. A shared `timeline_rows(events)` in `routes/awp.py` would remove it.
- `tl-tui` uses `tl_mod_awp` without declaring it. A ticket that names the import should also name the pyproject line.
- A `# fmt: skip` on the closing line of a multi-line call does not stop `ruff format`; reformat the file instead.
- Fake seed depths: a ticket that gives a seed shape should state the depth origin (0 for the top node) next to the numbers.
