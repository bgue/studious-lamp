## Learnings (proposed)
- The palette matches a command on its label, not its id: `cwps` opened the schema workbench. The driver types `Work packages CWPs`.
- `tl awp path move` prints the record version (`version 3`); read path versions with `tl awp path versions`.
- `tl awp package record` needs `--constraint-source` or `--no-constraint-source`. `tl proposal ls` needs `--project`.
- `tl cost import --as-of` refuses a future date. Rollup runs leave no ledger events; `tl cost snapshots` lists imports.
- `tl sim assert` excuses operator events only for `schedule.*` and `correspondence.*` records.
