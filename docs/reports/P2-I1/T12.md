## Learnings (proposed)
- `ruff format` must run on new test files before `just check`; the check recipe fails on unformatted files and the failure is easy to misread as a lint error.
- Pyright in `just check` flags `app.screen.rows` (Screen has no `rows`) and `notify(severity=str)`; annotating the palette as `Any` and the severity as `Any` in test helpers avoids it, as `dev/accept/P2-I1/T05h.py` does with `# type: ignore`.
