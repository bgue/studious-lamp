## Learnings (proposed)
- `tl load plan` needs the run to be Profiled first; the ticket's "open/extract/plan" sequence should say profile.
- A CWA plan counts the path as a new record, so "new" is areas plus one.
- Worktree path in the ticket (`/home/user/wt/i1-t01`) differs from the path the harness set (`/home/user/wt/i1/t01`).
- `tl load` acceptance needs `TL_OBJECT_ROOT` set to a scratch directory; otherwise `open` writes to `./dev/data/objects`.
