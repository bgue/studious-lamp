## Palette finds each entry by typing its id?
No. The palette fuzzy-matches command labels, not ids. Typing the label (for example "Work packages: CWPs, state, budget, allocation") ranks the right row first and opens the screen for all five. Typing the id does not:
- `cwps` ranks `schema` first (fuzzy match on "Schema workbench").
- `packages` ranks `cwps` first.
- `wbs`, `cwas` and `path` rank their own rows first.

## Learnings (proposed)
- The palette search (`build_rows` in `widgets/palette.py`) matches only `AppCommand.label`. The id is not searched, so a ticket that says "palette finds it by typing its id" will fail on short ids that are subsequences of other labels. Worth stating in the ticket template.
