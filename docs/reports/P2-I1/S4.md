## Learnings (proposed)
- `cur_core_record.status` is NULL until the first workflow move: read it as the initial state (`package_state`). A module event on a record stream needs a projector that calls `touch_record`, else the next `append` hits a stale version (`CWP.Released` has no column, only the touch).
- A fine access word is not the literal `"controller"`: any test that compares `spec.access` must use `effective_access`.
- Seeds that create CWPs must load `co.acme.standards@1.0.0` and `co.acme.awp@1.0.0` first (Discipline, UnitOfMeasure, Commodity, PathReason); the handlers fail closed without them.
