# Report — P2-W0 Roles MVP, offline classes, readiness, process tools, performance

Status: done; merged to trunk by the orchestrator. Branch `p2/w0`. Plan and board: `docs/tickets/P2-W0/` (README, STATE); spec `docs/build-spec/specs/wave0.md`; piece and ticket reports: `docs/reports/P2-W0/`.

## Objective
Per-module roles (viewer, user, superuser) that every controlling command checks by access word; an offline class on every record type (`full`, `draft_only`, `none`) with the capture hook that refuses online-only commands; the readiness words, reserved namespaces and settings keys wave 1 needs; the process tools A1 to A3. Owner additions during the wave: the everyday screens at 10,000 records, and "adopt this set" taking effect.

## What shipped
- **Module roles** (RM-S1 to RM-S4, RM-S3-L): role table `schema/settings/module-roles.yaml`, grants and revocations (ledgered, admin only, agents never), resolver with derived account roles (`document_controller` derives superuser in documents, correspondence, schedule; `user` derives user everywhere), effective-role views on API, CLI and TUI (`F10`, `m`). Every API, CLI and embedded gate checks the access word; refusal reads "<Cmd> needs the <word> access word for <module> on <scope>". Gate sweep pin: 0 ungated commands.
- **Offline classes** (OC-S1, OC-S2, T04 to T06, T08): `tl:offline` on every core and module type, `offline_class`, `capture_allowed`, `OnlineOnlyError` (409), load-time checks, node kind at start-up, `GET /record-types`, the Offline row in technical mode, scaffold default `none`.
- **Readiness and targets** (W0-B1, W0-B2): access words, reserved namespaces, 11 settings keys; load and publish targets by entry point.
- **Tools** (A1 to A3): `just state`, `just review-pack`, `just relay-lint`.
- **Performance** (PERF): document register 15.2 s to 0.27 s, RFI log 1.4 s to 0.23 s at 10,000 records; confidentiality pushed into each statement (`hidden_sql(only=)`, `visible_rows`), proved equal to the old SQL by differential tests on SQLite and Postgres. Report `docs/reports/perf/P2-PERF.md`.
- **Adopt one optional set** (ADOPT): `AdoptSchemaSet` publishes the next `x.<project>` extension in one transaction; refuses a package the project lacks and a conflicting pin.
- **Tests and docs** (S9, S10, T09 to T11): tests for every piece, runbook and access-words reference, `just demo P2-W0` (11 clauses).
- **End-run fixes**: FIX-REST (role-table error row, runner fakes), FIX-TUI (134 layout pins, 4 empty-value and 1 form fixes), TOUR (phase 1 tour tells the module-roles story, section 25), PGFIX (Postgres test setup seeds real accounts).
