## Learnings (proposed)
- `ruff format` does not wrap comments or docstrings, and `ruff check --fix` does not fix E501. Pasted interface blocks with long trailing comments (e.g. the `Event.actor` line) fail `just check` after the ticket's stated fix-and-format step, and need a manual rewrap. The ticket's style note could say so.
- `python-ulid` 2.x: `from ulid import ULID; str(ULID())` returns 26 characters with no extra setup, as the ticket assumed.
