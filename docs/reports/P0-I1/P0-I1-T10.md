## Learnings (proposed)
- A pydantic `ValidationError` from the command models is not a `ServiceError`, so it surfaces as a traceback with exit 1. Verified with `tl record create --project P123 --key X-1 --title ""` (`String should have at least 1 character`). The same applies to a bad `--project` character set and a blank `--reason` on void. AGENTS says let it surface, so the CLI is correct as specified; whether the services should convert these to `ServiceError` is a supervisor decision.
- Pyright standard rejects a `str` default on a `Path`-typed typer option. Declare it `str` and convert.
- After editing `[project.scripts]`, `uv sync --all-packages` is needed before `uv run tl` exists; it re-installs `tl-cli`.
- Typer's `CliRunner` (click 8.5) keeps `result.stdout` and `result.stderr` separate; assert `error:` on `result.stderr`.
