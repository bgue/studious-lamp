## Learnings (proposed)
- The ticket's seed snippet does not name the `Record.Created` payload fields. `RecordProjector` reads `payload["record_type"]` and `payload["title"]` unconditionally, so a payload of only `key`/`psets` fails. Ticket seed snippets should list the required payload keys.
- `UnitOfWork.ledger: Ledger` (a mutable attribute in a Protocol) makes every `SqliteUnitOfWork` non-conforming under pyright strict. Any caller that types a parameter as `UnitOfWork` will hit this, including the CLI. Declaring `ledger` as a read-only property in the Protocol should fix it. This is expected but not verified.
- `just check` runs pyright over `tests/` as well as `tl_core` source, so test helpers must type-check strictly. The ticket's learnings line mentions only `tl_core` source.
- Piping `just check` into `tail` hides the exit code. Redirect to a file and read `$?` instead.
