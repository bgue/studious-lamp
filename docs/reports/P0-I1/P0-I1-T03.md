## Learnings (proposed)
- A ticket docstring that quotes a triple-quoted string (`'"""..."""'`) cannot be pasted verbatim into a `"""` docstring; the file fails to parse with a SyntaxError that points at the docstring line, not at the cause. Escape the quotes or paraphrase in the ticket.
- Ruff's E501 (100 columns) applies to docstrings too. Pasted interface docstrings often exceed it; expect to rewrap them.
- The `grep -n "§4"` search on `docs/build-spec/01-tiers.md` returned nothing because the headings are written as `## 4. Implementer (Haiku)`. Search by heading text (`Implementer`) instead.
- A `timestamp` grep over generated output gives false positives from schema descriptions. Check for generation timestamps with a pattern such as `generated at` or `# timestamp:` instead.
