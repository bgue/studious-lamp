## Learnings (proposed)
- Pyright strict rejects `Mapping[str, Any]` as the parameter type for SQLAlchemy `.mappings()` rows (`RowMapping` has an invariant key type). Use `sqlalchemy.engine.RowMapping` as the parameter type for row-to-model helpers.
- `CursorResult.lastrowid` is typed `int` in SQLAlchemy 2.1, so a `cast(int, ...)` around it is flagged as unnecessary by pyright strict.
- The ticket's "17 tests" count does not match the provided file (16). Worth checking the count in the ticket template before quoting it in Expected lines.
