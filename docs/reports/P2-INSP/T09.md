## Learnings (proposed)
- The quality visibility tests do not define named readers; the five readers here are explicit `Viewer`s (plain user, document controller, admin, named user, agent), mirroring the awp `READERS`. A shared quality reader table would save the next card ticket this step.
- The card's checklist line shows the checklist key, not its title. A ticket that says "Checklist" should name which field it reads.
- Empty `scheduled_for` is not reachable through the commands (`ScheduleInspection` requires a date), so the bare `SCHEDULED` branch of `_banner` has no test.
