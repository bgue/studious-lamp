## Learnings (proposed)
- `tl init --dev` refuses unless `TL_ENV` is `dev`, `demo` or `test`; the Acceptance line omits it.
- A `just check` exit of 247 with no pyright output can be the recipe's pyright child being killed on a full disk or tight memory; a direct `uv run pyright` run distinguishes that from a code error.
- `just gate <path>` exits 1 when a shared test file also holds cases of a ticket not yet merged; `-k` shows one ticket's cases.
