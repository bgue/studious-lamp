## Learnings (proposed)
- `tl init --dev` refuses to run unless `TL_ENV` is `dev`, `demo` or `test`; the ticket's Acceptance line omits it and stops with `TL_ENV is 'unset'`.
- `just gate <path>` exits 1 when one file holds cases of two tickets and the other ticket's module is absent; `-k` on pytest is the way to see one ticket's cases.
- The MCP `call_tool` return type is a union (`InputRequiredResult` among others) in this MCP version; pyright needs `result: Any` at the call site to reach `structured_content`.
- `create_app(backend)` with default settings and `open_backend` from `tl_adapters.backend` worked for the driver without the harness's explicit `ApiSettings`.
