## Learnings (proposed)
- `confidentiality.current_viewer()` is only the embedded viewer inside the client's own uow (`embedded.py` sets it at `_uow`). A test that reads it outside the call sees the default viewer, so compare inside the patched function.
- `ruff format --check` in `just check` fails on a trailing blank line at end of file; run `ruff format <file>` before `just check`.
