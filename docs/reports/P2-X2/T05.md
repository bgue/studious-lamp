## Learnings (proposed)
- `events.event_type` is the column; `type` is not one. Ticket SQL should be checked against the DDL.
- A core command (`CreateRecord`) has no module word, so `require_command_access` skips it; accept by any signed-in person works. A demo of "accept needs the word" needs a module command.
- `accept_or_fail` records `Proposal.Failed` for any `ServiceError`, and `ForbiddenError` is one. A stop refusal therefore fails the proposal rather than leaving it pending.
- MCP tool errors carry a prefix; match service texts with `endswith`.
