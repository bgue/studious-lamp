## Learnings (proposed)
- `proposals.propose` returns `get_proposal`, which applies the viewer filter. Filing a proposal that carries a hidden record raises `ProposalNotFoundError`. File first, then classify the record.
- Unclassified records of a confidential record type are hidden from everyone (fail closed). A test that needs a visible record must classify it `internal` first.
- A signed-in admin is a controller (level 1) and reads `restricted`. "Admin without clearance" in a test needs a class that requires a clearance row (`privileged`).
- `hidden_among` only sees records that exist in `cur_core_record`; a random ULID hides nothing.
- Pyright's first run printed a path under another worktree (`/home/user/wt/tour2/s2/...`); the second run printed this worktree's path. Output may be stale.
