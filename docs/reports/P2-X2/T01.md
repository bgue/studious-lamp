## Learnings (proposed)
- Generated command routes (`/commands/<Name>`) bring their own body schemas named `<Name>Body`. A route body model with that name silently replaces them in `openapi.json`. Pick a distinct name.
- `proposals.propose` reads back what it wrote through the caller's viewer. A seed that files a proposal carrying a privileged record must run under `confidentiality.system_view()`, or it raises `ProposalNotFoundError`.
- Every generated `admin.command.*` action needs an `AGENT_MAY_NOT` or `AGENT_MAY` entry. A service ticket that adds commands must add the pin too.
