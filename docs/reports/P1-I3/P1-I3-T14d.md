## Learnings (proposed)
- `just check` runs `ruff check .` first and exits there on a lint failure, so the pyright, format and drift steps are not reached; run them one by one to see their status.
- `PlanRow.row` is stored as `row.line - 1` (0-based) in `publish.py::_plan_row`, but the class docstring says "1-based, header excluded". The `! row <n>` preview line prints the stored value, as `_publish`'s refusal text does. Which one is intended is an open question for the module.
- The ticket's Depends line lists S5, T14a and T14b, but the provided test calls `tl derive show`, which is T14c (`derive_read.py`). T14c should be listed in Depends, or merged before T14d.
- The ticket's Interfaces section names the `views` functions without signatures; the signatures are only in `views.py`.
