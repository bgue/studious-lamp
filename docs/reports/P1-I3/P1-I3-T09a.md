## Learnings (proposed)
- `uv run` prints `warning: The UV_NATIVE_TLS environment variable is deprecated` before every command in a fresh worktree. It is harmless, and it is easy to mistake for a failure when pasting output. A future ticket could say to expect it.
- The `MAX_BLANK_RUN` comment in `reading.py` describes a sheet ("a sheet that was formatted down to row one million"), but the CSV reader does not apply it: `test_blank_records_do_not_count_toward_the_row_limit` requires 30 000 blank lines to be read without a stop. The reader therefore reads any number of blank data records within the file size limit. This is consistent with the ticket, but a reader of `reading.py` would expect the CSV reader to stop, so the comment is worth narrowing.
