## Learnings (proposed)
- The ticket's *Interfaces* block says it is verbatim from the repo, but `derive_support.py` differs: `Actor` is `Annotated[str, ...]` with no `None` default, and `acting(db, actor: str)` takes a non-optional `str`. The stub's `validate` (`actor: Actor = DEV_ACTOR`) matches the real file, so the pasted block is stale. Check interface pastes against the file before relying on them.
- The Context list omitted the model that the `diff` body depends on (`DerivedDiff`, `RowChange`, `FieldChange` in `tl_mod_documents.derivation.diff`). Listing the module that defines the returned models would have saved a detour.
- `DerivedDiff.truncated` and `DerivedDiff.duplicate_keys` / `blank_key_rows` exist but the `diff` docstring does not name them, so the command prints no truncation notice. See the open question below.
- Timings on this machine: the provided test file takes about 80 s on SQLite and about 250 s with `--adapters sqlite,postgres`.
