## Learnings (proposed)
- pyright strict rejects `Text` cells added to a `DataTable[str]` (`reportArgumentType` on `add_row`), and `compose` declares `DataTable[str]`. The fix that kept `compose` untouched was a local annotation in `_fill`: `table: DataTable[Text] = self.query_one("#pp-table", DataTable)`.
- A `pgrep -f "just check"` wait loop matches its own shell command line, so it never exits. To wait for a backgrounded `just check`, wait on the task's completion notification, or poll the log for its last line (`licences ok`).
