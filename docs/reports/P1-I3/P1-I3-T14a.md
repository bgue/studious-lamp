## Learnings (proposed)
- ruff's E501 (100-column) check exempts lines ending in a pragma comment, so a 122-column `# pyright: ignore[...]` line passed `ruff check`. The line was only visible with `awk 'length > 100'`. Worth a check in the reviewer's checklist. In this ticket the long ignore was removed by typing the value with `cast` instead.
- `just check` and the two-adapter pytest run each take longer than the 120-second foreground Bash limit on a fresh tree; run them in the background and read the saved output file. Piping `just check` into `tail` would hide the exit code, so the output was saved to a file instead.
