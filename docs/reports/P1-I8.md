# Report — P1-I8 Schema workbench, legacy loaders, lake marts, Phase 1 exit

Status: done pending orchestrator merge to trunk. Branch `p1/i8` (head 79f2bcf). Plan and board: `docs/tickets/P1-I8/` (README, FANOUT, STATE); ticket reports: `docs/reports/P1-I8/`.

## Objective
A steward drafts a schema package, sees its classification and impact, has it reviewed and published, a project pins a version, and a time-limited waiver is the escape hatch. An admin loads a legacy file through extract, bronze, profile, plan, load and reconcile and can take a bad load back. The lake carries documents and schedule-history marts that never hold a row the lowest reader may not read. The Phase 1 exit chain (PDF, derived, published, feed, webhook receiver) runs as one demo.

## What shipped
- **Schema registry** (`tl-mod-schemareg`): `SchemaPackage` lifecycle (Draft to Retired), `Adoption` pins, `Waiver`, the ledger source feeding the effective schema; classification engine (`tl_schema.classify`, packages and LinkML) and impact report (records, columns, views, mappings, reports, MCP schemas).
- **Governance CLI**: `tl schema package draft|analyse|classify|diff|impact|test|submit|approve|publish|deprecate|retire`, `adopt|adoptions|drift`, `waiver request|approve|revoke|ls`, `crosswalk`, `conformance`.
- **Workbench TUI** (`Ctrl+O`): package tree, properties, lint, diff; review screen (`v`) with classification, impact, test on sample, submit, approve, send back, publish.
- **Waivers and conformance dashboard**: approved, unexpired waivers reach the evaluator through the effective schema; `conformance_dashboard()` counts records as the viewer, waived in its own field.
- **Export and import**: `tl schema export-git DIR` (published and deprecated text only), `import-git DIR [--dry-run]` (drafts only, all-or-nothing).
- **Legacy loaders** (`tl-mod-legacy`, `tl load`): `LoadRun`, the stage framework, compensation; loaders `dms-register`, `instrument-index`, `equipment-list`.
- **Lake**: documents silver, marts `mart_document_status|turnaround|issues` and `mart_schedule_history`; `tl lake mart ls|show`.
- **Demo**: `just demo P1-I8`, seven clauses, both adapters.
- Pieces S1 to S6, S9, S10; tickets T03, T04a, T04b, T05a1 to T05a4c, T07a, T07b, T08, T09a, T09b (all merged).
