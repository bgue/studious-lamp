## Learnings (proposed)
- A static token from `tl_api.tokens.add_token` carries no roles: an `ApiClient` built on it reads as a no-role viewer (dora did not see a restricted-source item; a verify was refused by the access gate). Per-person clients need `tl_core.auth.sessions.sign_in`, as the T03 test does.
- `tl_api.client.base._model` / `_models` take pydantic models only; `tl_mod_quality.views` returns stdlib dataclasses, so `quality.py` decodes them with `TypeAdapter`. Worth a note if more dataclass views get clients.
- `ruff format` in a `just check` pre-step can rewrite files you just wrote; E501 at 100 columns caught two long lines.
