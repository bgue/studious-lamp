## Learnings (proposed)
- `ApiClient` raises the service `RecordNotFoundError` for a 404, not `ApiError`; a failed MCP tool raises `ToolError` from `call_tool` rather than returning `is_error`. A driver must catch both.
- Both backends share one workdir: per-backend scratch files (loop outputs) must be cleared at the start of each pass, or the second count doubles.
- A restricted correspondence item is readable only by admin or document_controller accounts; a demo that needs a named person to see it must give that role.
- A background gate run killed at the 600s tool limit leaves an empty `.gate/summary.txt` and no verdict; run `just check` and `just demo` in the foreground or with explicit exit-code capture.
