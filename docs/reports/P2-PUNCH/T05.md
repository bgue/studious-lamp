## Learnings (proposed)
- `just check` does not run the MCP schema tests; a new string tool argument with no `max_length` only fails in `test_mcp_write_tools.py::test_every_string_the_tools_accept_has_a_length_limit`, which the gate runs. Put a length on every `str` argument (dates included) from the start.
- A tool error reaches the test as `Error executing tool <name>: <message>`; compare the message after that prefix.
