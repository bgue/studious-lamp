## Implementation notes
- Hidden filter: `not_hidden("r.id")` (set form) in list and counts, `not_hidden_each` in detail; both in the WHERE, before LIMIT.
- `punch_list` runs two statements (COUNT for `total`, then the page with `LIMIT`); `punch_counts` one GROUP BY on `r.status`
  (None maps to Open); `punch_detail` one statement. Source key and source type from one LEFT JOIN on `source_id`.
- Overdue is `COALESCE(status, Open) = Open AND due_on < today` as text; the views never read the clock.
- `MSG_CATEGORY` is imported from `tl_mod_quality.api` so the category error text is the same as `open_punch_for`.

## Learnings (proposed)
- `dict.fromkeys(<tuple of str literals>, 0)` infers a `dict[Literal[...], int]`; pyright then rejects returning it as `dict[str, int]`.
  Annotate the local (`counts: dict[str, int] = ...`). Not in the ticket; cost one `just check` round.
- `ruff format` reflowed one `conn.execute(...)` call in the new file; run `ruff format` on touched files before `just check`.
