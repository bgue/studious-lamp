## Learnings (proposed)
- An Open punch item has `cur_core_record.status` NULL; use `COALESCE(status, 'Open')`. `source_id` is a random id per run; compare source keys across runs.
- `World.run` sets no viewer; a restricted source must be raised under `use_viewer(viewer_for_actor(...))`.
