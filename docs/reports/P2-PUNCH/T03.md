## Learnings (proposed)
- `tl_mod_quality.views` default `viewer=LOWEST` ignores the request's ambient viewer (`current_viewer()`), unlike `not_hidden`, which falls back to it. A route must pass the viewer explicitly, or a controller reads as the lowest class.
- `accounts.create_account` needs at least one of `admin`, `document_controller`, `user`; a no-role reader cannot be built in a test.
- `just gen` writes only the generated schema tree; `docs/reference/openapi.json` is written by `python -m tl_api.openapi` and drift-checked in `just check`.
- The quality package lives at `packages/tl-modules/quality/`, not `packages/tl-mod-quality/`.
