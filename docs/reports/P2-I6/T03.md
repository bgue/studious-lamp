## Learnings (proposed)
- `grep -c` on `openapi.json` counts matching lines, not paths; with a single-line-per-path layout it is still usable, but the route list needs `grep -o '"/[^"]*"'`.
- `tl req ls --state` takes a state name, but the help does not list the states; "open requisitions" therefore cannot be matched to a named state without reading `req_read.py`/the state machine. The supervisor may want a note in the runbook.
