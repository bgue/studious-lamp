## Learnings (proposed)
- A single pytest session in parts 1 and 4 reaches about 12.5 GB anonymous RSS and hits the sandbox cgroup limit (`oom-kill ... CONSTRAINT_MEMCG`); splitting into more parts avoids it.
- `dev/gate.sh` prints only at the end, and `pgrep -f dev/gate.sh` matches its own shell; run the gate with `setsid` so tool cleanup does not SIGTERM it.
- `dev/gate.sh` writes `.gate/part-N.log` and prints the verdict to stdout; it does not write `.gate/summary.txt`, so a worktree without the harness shows no summary file.
- `tl req ls --state` takes a state name that `--help` does not list; "open requisitions" needs `req_read.py` to resolve.
