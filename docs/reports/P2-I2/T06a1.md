## Learnings (proposed)
- `iwp_facts.pinned_document_links` lists only active, pinned links, so a stale pin (link status `stale`) and a floating pin never reach a readiness check. A check that follows the ticket's rule cannot see the case it exists for.
- Writing a document with `confidentiality="restricted"` through the commands fails with `RecordNotFoundError` under the default viewer (the record it just wrote is hidden from it). Create, issue and read such a document inside `tl_core.confidentiality.system_view()`.
- `ruff format` rewrites files in place; a formatter run on several files reports them as "changed on disk" to an editing agent.
