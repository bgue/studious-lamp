## Learnings (proposed)
- `typer.testing.CliRunner().invoke(app, args, obj=target)` sets `ctx.obj`, so a throwaway Typer app can take a `DbTarget`. `--actor` for a non-session user needs `TL_ENV=dev` set in `os.environ` before the call.
- An IWP's record key is its number, so `cur_core_record.key` answers the number lookup directly.
- Pyright rejects a `dict[str, type[Command]]` table called with the subclass fields (`iwp=`, `reason=`); typing the table as `Callable[..., Command]` is the fix.
