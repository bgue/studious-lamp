## Learnings (proposed)
- The suite loads only `co.acme.standards` and `co.acme.documents`. The Commodity list is in `co.acme.awp`, and `EA` is in `co.acme.materials`. The test loads the awp file itself, as `awp_world.py` does.
- `CreateScopeItem` checks `uom` against `UnitOfMeasure`, which has no count unit.
- `list_iwps` takes a bare project id (`sim-rt1`), not `project:sim-rt1`.
- The suite provisions identities as tokens only. A manual constraint's owner needs a `cur_account` row, which nothing in the suite creates.
