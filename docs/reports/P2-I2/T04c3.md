## Learnings (proposed, not written to docs/memory)
- The ticket's F3 note ("a key is unique per type, not per scope") is inaccurate: the current-state index makes keys unique per scope.
- The `test_auth_review.py` walk found five IWP `control.command.*` actions with no agent decision on p2/i2. The pin sets had to be extended, which the ticket did not anticipate.
- Dev tokens need `TL_ENV` set to dev, test or ci (`auth/env.py`), otherwise a dev-token reader gets 401 in a script.
