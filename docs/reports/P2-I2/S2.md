## Deviations
(1) `RaiseConstraint` names the source `source_kind`: `Command.source` is the caller, so a `source` field clashes. (2) `contains` cannot be written forward (`tl_core.links.vocabulary` holds it as the inverse of `belongs_to`; `handle_add_link` refuses it): scope is a `belongs_to` link, source `rule`, from the item to the IWP. `facts.py` (S1) now reads both (its old `contains` branch stays, so S1.py still passes). `names.py` `SCOPE_RELATION`. (3) `CommandResult` has no warning field, so the sizing warning is a `guards_evaluated` entry `{kind: iwp_size, passed: false, message: <code>}` in the payload of the last IWP event of the command: the key and entry shape `Workflow.Transitioned` uses for a release's missed expected links (attempt 2 aligned it; was `warnings`). (4) A check constraint keeps its facts hash in `Constraint.Raised.suppress_hash`, and `Constraint.Cleared` carries `suppress: true|false` (person or check clear; the projector drops the hash on false): no `facts_hash` column exists. (5) `owner` is `user:<name>` only (column pattern; no module-role actor text fits). (6) No `ReviseIwp` command is in the brief table, so IWP fields change only through scope recompute. (7) `dev/accept/P2-I2/S2.py` is 23 lines (cap 70); checks and seed live in `awp/tests/s2_checks.py`, helpers in `tests/awp_world.py`. (8) `docs/reference/openapi.json` regenerated (new routes); `just check` runs `tl_api.openapi --check`, so the committed file must carry them (earlier pieces commit it too). (9) Document pin reads `v_documents_revision` by SQL (awp may not import documents). (10) The one-IWP rule covers `ScopeItem`s, not tags.

## Learnings (proposed)
- `contains` is only the inverse of `belongs_to` in the vocabulary: any "contains" link a brief names is stored `belongs_to` the other way round.
- `CommandResult` is the API response model: extra result fields never reach a client; put them in an event payload.
- The workflow `Void`/`Cleared` states live in `cur_core_record.status` (NULL before the first move); read with a default.
