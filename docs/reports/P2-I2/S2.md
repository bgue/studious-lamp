## Deviations
(1) `RaiseConstraint` names the source `source_kind`: `Command.source` is the caller, so a `source` field clashes. (2) `contains` cannot be written forward (`tl_core.links.vocabulary` holds it as the inverse of `belongs_to`; `handle_add_link` refuses it): scope is a `belongs_to` link, source `rule`, from the item to the IWP. `facts.py` (S1) now reads both (its old `contains` branch stays, so S1.py still passes). `names.py` `SCOPE_RELATION`. (3) `CommandResult` has no warning field and the API serialises only it, so the sizing warning is `warnings: [code]` in the payload of the last IWP event of the command (`IWP.Created`, `IWP.Revised`, `IWP.ScopeAdded/Removed`); the way `Workflow.Transitioned` carries a release's missed expected links. Undeclared payload key (catalog `detail` allows extras); a schema declaration is for a later piece. (4) A check constraint keeps its facts hash in `Constraint.Raised.suppress_hash`, and `Constraint.Cleared` carries `suppress: true|false` (person or check clear; the projector drops the hash on false): no `facts_hash` column exists. (5) `owner` is `user:<name>` only (column pattern; no module-role actor text fits). (6) No `ReviseIwp` command is in the brief table, so IWP fields change only through scope recompute. (7) `dev/accept/P2-I2/S2.py` is 205 lines formatted (cap 70); 23 checks do not fit. Helpers (`iwp`, `items`, `set_status`, `column`, `module_call`, `documents`) went into `tests/awp_world.py`. (8) `docs/reference/openapi.json` regenerated (new routes). (9) Document pin reads `v_documents_revision` by SQL (awp may not import documents). (10) The one-IWP rule covers `ScopeItem`s, not tags.

## Learnings (proposed)
- `contains` is only the inverse of `belongs_to` in the vocabulary: any "contains" link a brief names is stored `belongs_to` the other way round.
- `CommandResult` is the API response model: extra result fields never reach a client; put them in an event payload.
- The workflow `Void`/`Cleared` states live in `cur_core_record.status` (NULL before the first move); read with a default.
