## tui-layout checklist
1. Glance: the log answers number, subject, state, foreman, hours; the panel answers identity, state, summary, then sections.
2. Identity first: identity line is `number · title`; scope/sign-off values use labelled props; Drawings and Constraints are count lines (ticket format).
3. Sections named (Scope, Sign-offs, Drawings, Constraints), ordered by need, one blank line between (layout.page_lines).
4. Tiers: page shows everyday fields only; the technical flag changes only a sign-off's actor (id instead of name); no record hash is ever shown.
5. Log columns: Number, Subject, State first; Subject is column 2; no sideways scroll at 80 or 170 (acceptance checks line widths and header order).
6. Panel: summary under state; discipline/window/hours appear once (summary), not repeated in sections; scope rows and sign-offs are small tables.
7. Empty values: open lists use notes (`No scope`, `No sign-offs`); fixed counts always show (`0 pinned`); empty table cells show `—`.
