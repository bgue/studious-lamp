## Learnings (proposed)
- `core.constraint.view` needs table word `read`, which every person role holds. A "viewer without the word" can only be built as a holder with no account (a `svc:` actor), so the next refusal test should say so up front.
- `person()` in `awp_world` raises `InvalidAccountError` for roles `()`.
- `get_record` (`services/queries.py`) already applies the ambient viewer through `_one`; wrap it in `cf.use_viewer` and the key lookup respects the viewer without extra code.
- Each `sessions.sign_in` + `session.save` replaces the one session entry of a ledger, so a multi-user check signs in again per user.
- B023 fires on lambdas built in a loop; `functools.partial` avoids it.
