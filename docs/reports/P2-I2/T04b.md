## Learnings (proposed)
- `humanize("rfi")` gives `Rfi`, and `humanize("labour")` gives `Labour`; the constraint type words may need a code list or an acronym rule before the web twin copies them.
- `ConstraintRow` is a dataclass (`replace`, not `model_copy`); `IwpRow` in the same seed is pydantic. Test code that copies rows must know which.
- `list_iwps` sorts by number, so `[0]` is the CIV IWP with no constraints; a subject test must name the PIP IWP.
- Reading `#log-status` after `run_pilot` returns raises NoMatches; read it inside the pilot steps.
