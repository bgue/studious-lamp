## Learnings (proposed)
- `proposals.submit` runs a precheck as the proposing actor (`precheck(... command.model_copy(update={"actor": agent}))`). A proposal's command therefore needs the access word for the proposing agent, not only the accepting person's `user` word. `RaiseConstraint` needs `core.constraint.edit`, which agents do not hold. `AddIwpScope` passes the same precheck.
- The MCP server test pins the exact tool set (`test_mcp_server.py` `TOOLS`), so every new tool fails it until that file lists the tools.
