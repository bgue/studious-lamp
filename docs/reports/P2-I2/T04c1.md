## Open questions / Blocked
BLOCKED: the readiness route (`/awp/iwps/{number}/readiness`) is not written. Decision D20-22 says the read drops hidden ids from `resolve_via` and counts only visible ones, and the twin test needs a byte-identical body. `tl_mod_awp/readiness/views.py:readiness` does neither: it returns `resolve_via` and counts as the engine wrote them. The check (`readiness/checks.py`, constraints) counts all constraints, hidden ones included, so a route can leak a hidden count. The fix belongs in `views.py`, which is outside Allowed paths, and a route cannot recompute `count_ok`/`count_total` from the view. Question for the supervisor: approve a change to `readiness/views.py` (drop hidden refs and count visible only, with a new count rule), or accept the readiness route as a follow-up ticket.
Also: `GET /constraints/groups` groups at most the first 500 visible constraints (the view's `MAX_LIMIT`); a larger project is silently truncated. Confirm this is acceptable or ask for a 422.
