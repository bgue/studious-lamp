## Learnings (proposed)
- `readiness` is in `tl_mod_awp.readiness.views`, not `tl_mod_awp.views`.
- `readiness.views` does not filter `resolve_via` by viewer: a restricted record named by a check is returned with its
  id and key to the lowest clearance. Any reader of that view needs a viewer filter on the refs.
- AWP records have no class (D22). A hidden IWP in a test has to be simulated by patching `tl_core.confidentiality.is_hidden`
  (the view reads that); `iwp_list` filters in SQL, so `ls` still lists the simulated IWP.
