## Learnings (proposed)
- A fresh worktree needs `uv sync --all-packages`. Plain `uv sync` installs no workspace packages, so
  `uv run tl` fails with "Failed to spawn: `tl`".
- `tl record create --toward` needs a real state (`target:state`) of the target; for a record the
  driver uses `target:~cured`. A wrong state fails with "intent toward state is not a state of the target".
- `tl archive verify --db URL` prints the URL with the password masked (`postgres:***`).
- The first run of this driver failed at the pytest step with no captured output; the same step and
  the whole demo passed on the next three runs. The driver now keeps pytest's output on failure. Cause
  not found.
- `intent_lines` in plain mode shows a toward target as its raw id unless `names` maps id to key; the
  helper passes no `names`.
