## Learnings (proposed)
- A fresh worktree needs `uv sync --all-packages`; plain `uv sync` installs no workspace packages and
  `uv run tl` fails with "Failed to spawn: `tl`".
- `tl record create --toward` needs a real state (`target:state`) or a condition (`target:~cured`); a
  wrong state fails with "intent toward state is not a state of the target".
- `pytest --collect-only` without `-q` puts the count inside `====` bars; do not anchor the parser.
- The full demo takes about 9 minutes; run it in the background.
- The first run of an earlier driver version failed at the pytest step with no captured output; the same
  step passed on the next runs. Cause not found; the driver now keeps pytest's output on failure.
