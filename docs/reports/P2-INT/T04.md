# P2-INT-T04 - Intent in the TUI (Activity tab)

## What was built
- `tl_tui/intent_text.py`: `intent_lines(intent, *, technical, names)` (pure; provided test moved unchanged
  to `packages/tl-tui/tests/test_intent_text.py` with `git mv`).
- `widgets/activity_tab.py`: a `Static` `#activity-why` under the table, in both full and Revisions-only
  modes, showing the lines of the highlighted row's event; empty and hidden when there is no intent.
  Names (id -> key) come from `client.get_record_by_id`, client errors ignored (the id is shown);
  technical mode shows raw ids. Table cells are unchanged.
- `embedded.history` passes its result through `redact_events`.

## Deviations from the ticket (orchestrator amendment)
- The ticket named the History tab; P2-INS replaced it with the Activity tab, so the panel is there.
- Security fix in core: `record_activity` returned `ActivityRow.event` with an unredacted intent, so
  `GET /records/{id}/activity` and the embedded client could leak the id of a record the viewer cannot read.
  The page's visible events now pass `redact_events(conn, ...)` before rows are built.
- Found while testing: `_load` in `insights/activity.py` did not select the `intent` column, so activity
  rows never carried an intent at all (the panel would have stayed empty). The column is now selected.
- "Byte-identical to an unknown id": `redact_events` shows a hidden reference as "not available" and
  leaves a stored dangling id as it is (nothing to protect). The twin therefore compares a hidden
  reference with an intent stored as "not available" (target-only toward, text-only next).

## Tests

  sees the id, Revisions-only is redacted too.
- `tl-api/tests/test_activity_intent.py`: `/records/{id}/activity` as bob and amy, both modes, both places.
- `tl-tui/tests/test_history_intent.py`: plain and technical panel, no intent -> empty and hidden with cells
  equal to `activity_cells`, "not available" as is, cursor movement, Revisions-only, embedded `history` and
  `activity` redaction (a controller still sees the id).
