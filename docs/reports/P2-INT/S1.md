## Learnings (proposed)
Optional-part hash rule: a hash input that did not exist before is appended only when present, never as an empty part, so every old digest stays valid; the stored text and the hashed text come from one function. Adding a typed optional field to a widely `**dict`-unpacked pydantic model breaks pyright at every `dict[str, str]` call site.
