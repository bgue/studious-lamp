## Learnings (proposed)
- `just check` with pyright on this repo can exhaust Node's default heap (JS OOM, recipe exit 250); `NODE_OPTIONS=--max-old-space-size=6144` made pyright finish. Worth a line in the runbook or the justfile.
- The ticket says "12 submit calls in 8 modules"; grep finds 13 (write_tools has 5). The tool list in the ticket is right.
- The MCP framework prefixes tool errors with `Error executing tool <name>: `, so tests must match the code with `in`, not `startswith`.
- An extra key in the intent (`evidence`) is refused by the tool's argument model before `validate_intent` runs, so the text is a pydantic message, not `intent_invalid`.
