- `SchemaView` induced-slot annotations can be a `JsonObj` without `.get`; test with `in` and `[]` instead.
- Synthetic LinkML schemas used in tests must not `is_a` a core class unless the test also imports core; `EventPayload` is not in the synthetic schema.
- The ADR-0026 F5 approval line for this schema change is not yet in `docs/reports/APPROVALS.md`.
