## Tests added (`packages/tl-cli/tests/test_intent_cli.py`)
- `record create --why --toward KEY:~released` stores canonical JSON with the target id, no key.
- No options gives a NULL intent column.
- Unknown and unreadable (hidden) keys give the same `error:` text, exit 1, nothing appended.
- `link add --why` carries the intent on the link event; `retract` takes the options.
- A 501-character `--why` is refused before any event.
- Malformed `--next` and `--toward` give `error:`, exit 1, nothing appended.
- `--next` and `--goal-ref` are stored; help names the four options (record, link).
