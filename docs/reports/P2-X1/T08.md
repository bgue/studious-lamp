## Learnings (proposed)
- `tl_api.openapi --compat` never reads `OPENAPI_PATH`. A demo or test that points only that constant at a scratch file tests nothing; the baseline side has to change.
- The `tl admin token issue` token is the first stdout line; the stderr line says it is shown once. The shell writes it to a file and never echoes it.
- The demo shell's `drop_pg` ends in `|| true`, so a failed scratch-database drop is silent. Four old `tl_pytest_demo_*` databases on the dev server show it happens.
