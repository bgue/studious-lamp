## Key format and retry rule
- Key: `uuid.uuid4().hex` (32 lowercase hex chars, printable ASCII, no space). Generated once per `_send` call, before the first attempt. A key already in the body (non-None) is never replaced.
- Retry: only for `POST` with path starting `/commands/` and a dict body. It is sent again on `_RESET` (ReadError, WriteError, CloseError, RemoteProtocolError) or `httpx2.TimeoutException`. A second failure raises `ApiUnavailableError` with the last cause. Status 400+ is never retried. A refused connection is raised at once.
- GET: unchanged (retried on reset only, timeout not retried). Other POSTs and PUT: single send.
- The provided `packages/tl-api/tests/test_client_idempotency.py` is byte-identical to `docs/tickets/P2-X1/provided/test_client_idempotency.py` (`cmp` silent, 101 lines unchanged).
