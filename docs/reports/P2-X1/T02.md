- Keyed request = method POST, path starts with `/commands/`, json is a dict. Caller's key (non-None) is kept.
- Key generated once per `_send` call, before the first attempt.
- Retry: `_RESET` (ReadError, WriteError, CloseError, RemoteProtocolError) and `TimeoutException` retried once for keyed requests; `TimeoutException` on any other request raises `ApiUnavailableError` at once; GET keeps reset-only retry; error status (400+) never retried.
