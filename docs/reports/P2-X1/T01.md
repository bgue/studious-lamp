## Answer to the ticket's report question
The 422 body for a bad key does not echo the input. `Command` has `hide_input_in_errors=True`, and the tests assert the key text is absent. No escalation was needed.

## Learnings (proposed)
- A bad header value reaches the command model validator through `spec.model(**fields)`, so the code is the generic `validation_error`. The ticket's `invalid_idempotency_key` applies only to the header/body mismatch path, which the ticket's error table implies but does not state.
- `python -m tl_api.openapi` has no regenerate flag: it writes the file when run with no arguments and checks with `--check`.
