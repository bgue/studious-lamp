## Learnings (proposed)
- A new directory under `packages/tl-modules/` without a `pyproject.toml` breaks every `uv run` and `just` recipe, because
  the root workspace glob matches it and `exclude` names only the bare directory. Data-only tickets that create a module
  folder ahead of its package need that pyproject first, or a workspace fix.
- `uv run --no-project <tool>` still runs ruff while the workspace is broken; use it for lint evidence only.
