## Deviations
1. **Target names use an underscore**: `materials_item_master`, `materials_location`, `materials_po_line`. The
   `throughline.load_targets` group allows `^[a-z][a-z0-9_]*$` (W0-B2); a dotted name makes `load_targets()` raise and
   would break `tl load` for every target. Constants `TARGET_*` in `names.py`; T01b's loaders use them.
2. **Not the generic `mapping_target`**: it writes only `Record.Created` (title, description), so no typed row would
   exist. `targets.py` has its own column-mapping targets that plan through `check_define_item`,
   `check_define_location` and `check_record_po_line` and apply through the command handlers. They import `Plan`,
   `Created`, ... from `tl_mod_legacy.targets`; the spec allows entry points only, so no `tl-mod-legacy` dependency is declared.
3. **Red tests that need files outside my paths (glue)**: `tests/services/test_module_role_seams.py::
   test_every_module_row_of_the_api_table_is_in_the_index_and_nothing_else_is` (the API table lacks the materials
   rows: `_module_specs("materials", MATERIALS_COMMANDS)` in `tl_api/commands.py`, then `"materials"` in
   `API_COMMANDS_OF`) and `packages/tl-api/tests/test_error_table.py::test_every_service_error_has_its_own_row` (rows
   for the 14 classes of `tl_mod_materials/errors.py` in `tl_api/errors.py`). Both stay red until the supervisor's glue.
4. `command_words` also carries `IssueStock`, `TransferStock`, `ReturnStock` (`DRAFT_COMMAND_WORDS`, `materials.move`):
   `check_offline` needs them for `offline_drafts`; S3 replaces them with its rows.
5. Spec silent, so I chose: reserve, unreserve, issue, scrap, adjust-out use `from_location_id`; receive, return,
   adjust-in use `to_location_id`; absent `supplier_text` is stored `""` (NOT NULL column); `ItemCategory` and
   `MaterialCode` are shape-checked, `StockUom` and `LocationKind` checked against the closed lists; the projector
   raises on a negative balance (a last line behind S3's check).

## Learnings (proposed)
- A load target name cannot hold a dot, so `materials.item_master` is not loadable.
- S1's samples of `MTOLine.Defined.mto_id` and `MTOLine.Assigned.work_package_id` are 27 characters, not ULIDs.
- SQLite hands a NUMERIC back as float: read `Decimal(str(x))`, compute in `Decimal`, bind `float(...)`.
