## Learnings (proposed)
- `KEY_CELLS` puts `2 short only` on the keys row, so the words are always on screen. Screen checks must match the summary phrase `lines · short only`.
- Seed MTO line keys carry a random four-hex suffix (`ISO-1234@A/MTO/001-xxxx`); acceptance scripts must read keys from the ledger.
- S5 `need_by` is always None, so `Need by` is always dropped by `columns_for`.
- A foreground `sleep` of 60 seconds is blocked in Bash; use `run_in_background` to wait.
