## Learnings (proposed)
- An account-less `user:` actor on a dev ledger holds only the `user` word (`dev_ledger` in `tl_core/auth/module_roles.py`), so a seed actor cannot stand in for a controller. A controller check needs an account with an explicit module grant; the acceptance copy makes one.
- `ForbiddenError` text is `<Command> needs the <word> access word for <module> on <scope>`, printed as `error: forbidden: ...`.
- The materials Python package is `tl_mod_materials`, installed from `packages/tl-modules/materials/src`, not from a `packages/tl-mod-materials` directory.
- In this environment a background command cannot be stopped with a task-stop tool (none is listed); it was stopped by its PID, not by name.
