## Decisions made (check these)
- A published derived document cannot be published again, so skip_existing is shown on a second derived document of
  the same revision (`mto-b`): plan `exists` 3, publish refused "nothing to create" (pipeline rule), nothing written.
  A row with no line under a live take-off is `differs`: counted, never added.
- Republish after compensation: a voided key stays taken, so the new take-off is `ISO-1234@A/MTO-2` (lines `…-2/001`).
- `mto_lines` of `AssignMtoLines` are line keys; a line already on the work package is skipped, none to move is
  `NoChangesError`; an issued line is refused like a reserved one. `PublishDerivedMto`'s work package reaches `create`
  through a context variable (the pipeline's `create` takes no extra argument).
- Compensation retracts the module-written links (`import`, `rule`) of take-off and lines, then voids lines, then MTO.
- A tag key that does not exist leaves `tag_id` null (spec: "if the key exists").
- No awp module on the trunk: acceptance appends `awp.CWP` / `awp.IWP`, the tag and the stock movements by hand.
