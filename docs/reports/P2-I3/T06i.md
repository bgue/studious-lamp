## Learnings (proposed)
- A two-row Delete check cannot catch a reset to row 0. The last row of two rows is row 1, and `min(row, len-1)` on a reset also gives row 0 for a one-line result. Pin the last-row case on a table of three or more rows.
- `DataTable.clear()` puts the cursor back on row 0, so a cursor restore has to read `cursor_row` before the clear.
