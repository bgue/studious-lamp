## Learnings (proposed)
- `FakeClient` mixins share one attribute namespace: `_rows` is already the schedule fake's dict, so a helper named `_rows` raised `TypeError: 'dict' object is not callable`. Name fake helpers per feature.
- The `tl_api` harness reads its dev token file only when `TL_ENV` is dev, test or ci; a standalone script must set it (as `S4.py` does), or every request is `unknown token`.
- An actor with no account reads at the lowest clearance on both the embedded client and the API. A direct view call with `viewer=None` sees everything. On the S3 seed the two agree.
