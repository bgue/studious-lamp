## Learnings (proposed)
- `tl mat move --for-line` and `--for-cost-code` take record ids, but no read command prints a record id (`mto show` and `mto list` print keys). Reserve from the CLI cannot be done from the CLI output alone.
- `tl derive publish` branches only on tags vs everything else (`derive_publish.py`, ~line 134). An `mto` mapping would take the documents branch; I read this and did not run it.
- `materials.Receipt` is `draft_only` in the schema, but the module registers no drafting commands for it.
- No `tl mat` command for DefineItem, AdoptItem, DefineLocation or PublishDerivedMto. The readiness check `materials_reserved` has no CLI, API or TUI caller in the source.
- `tl mat receipt accept` has no `--expected-version` (spec §3 lists one).
