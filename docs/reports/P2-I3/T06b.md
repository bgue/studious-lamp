## Learnings (proposed)
- `layout.Section.note` shows only when a section has no items. A section with a line item (the missing-MTR line) and no files shows no `No files`; the line alone says it. Worth stating in the text contracts.
- A plain `str` item carries no colour. A coloured line needs a styled `Cell` in a `TableRow`, which reads as a row (and so was wrongly taken for a file). For the text contracts and the layout follow-up.
- In the S3 seed, the panel's state line reads `Accepted · since <today>`, so the since date changes on each run.
