## Learnings (proposed)
- A record of a confidential type with no row in the class table is hidden (null class); a test table must give every record of those types a class.
- `awp.CWP` is not owned by an installed module yet, so a work package cannot be hidden by class; the line hides its work package name.
- The API error body key is `error`, not `code`.
