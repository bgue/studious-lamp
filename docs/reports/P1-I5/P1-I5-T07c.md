## Learnings (proposed)
- `just check` runs pyright over the whole repository before the codegen-drift, OpenAPI-drift and licence steps. A pyright failure anywhere (here, the TUI fakes) hides the result of those three steps. To see them, run each one directly, as above.
- The ticket's Context list does not include `catalog.py`, but the STEPS call `catalog.check_subtype` and the stub imports `catalog`. The call worked as written, so no read of `catalog.py` was needed. An implementer who does not know its signature will need it added to Context.
- Once `STUB`, `STEPS` and `ruff: noqa` are removed, the stub's unused imports become ruff F401 errors. `Event` stays in use only through the `answered: list[Event]` annotation, which pyright needs for `answered = list(result.events)`.
