## Learnings (proposed)
- A `text()` SQL string written as one f-string line longer than 100 columns fails ruff E501 and is reflowed by `ruff format`; writing the SQL as implicit concatenation of short string pieces avoids both on the first try. Candidate for the L-P0-I1-6 family.
