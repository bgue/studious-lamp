twice. I followed STEPS (the explicit algorithm). No committed fixture and no test has a keyword
shared across subtypes, so both readings pass. Decide whether cross-subtype duplicates should
count once.

**Open question (edge, not reachable via `DomainSet`):** if the `domains` argument holds two
definitions with the same `code` (different scope or semver), `scores[code]` keeps the last one and
`chosen` takes the first. `DomainSet.for_scope` gives one per code, so the caller is safe. Confirm
that callers always pass one definition per code.
