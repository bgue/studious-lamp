## Learnings (proposed)
- A ticket's expected test counts should come from the provided file (`grep -c "^def test_"`), not from a hand count. This ticket said 14 and 28; the file has 15 and the run gives 15 and 30.
- `Write` on a stub file failed with "File has not been read yet" even though the ticket pasted the full file text. The pasted interface does not count as a read; a `Read` of the file on disk is needed first.
- In `find_match`, the STEPS loop variable `found` would be reused in two loops with different meaning; I named the number-lookup result `known` for readability. Behaviour is the STEPS behaviour.
