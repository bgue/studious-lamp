## Learnings (proposed)
- The ticket's expected counts (13 SQLite, 26 both) disagree with the provided file (15 functions).
  The file is the contract; the counts in the ticket should be taken from `grep -c "^def test_"`
  times the adapter count, not typed in by hand.
- The provided test file fails this repo's `just check` (E501 at line 268, a signature longer than
  100 columns, and the matching ruff format diff). A provided test should be checked with `ruff` before
  it is handed to an implementer, because the implementer may not edit it.
- Running `ruff format` on the module file rewrapped one line of my code and the tool reported the
  file as modified on disk; that is expected and not a conflict.
