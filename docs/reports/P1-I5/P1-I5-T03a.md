- `Correspondence.Updated`: the SET clause is built only from `_UPDATABLE` columns whose field name is a key of `changes`; the column names and bind names come from that constant map, never from the payload. `to`/`cc` store `json_text(new or [])`. - `ClearanceWithdrawn` is a DELETE with no row-count check, as the STEPS say (only UPDATE branches check).
- `response_required` is passed as a Python bool.
