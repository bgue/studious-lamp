## Learnings (proposed)
- The STEPS comments wrap long string literals across comment lines, and a comment wrap stands for a space, not a newline. Read literally, `BT` / `/F1 ...` and `b")` / `Tj T*` would lose their separators. The provided test confirms the space: it expects `(Subject: ...) Tj`. Also `trailer ... /Info 4 0 R` / `>>` is written `R >>` on one line. A short note in the ticket template would save a reader a minute.
- The tier table in `AGENTS.md` says an implementer reads `docs/build-spec/01-tiers.md` §4 before the ticket's context list. This ticket's *Context* section says "read these, nothing else", and I followed the ticket. The two instructions differ; the supervisor may want to say which one wins for implementers.
- The ticket's Steps and the tier doc do not say to run `uv sync --all-packages` in a fresh worktree; the workflow harness asked for it, and the test ran only after that sync. I did not test whether a plain `uv sync` is enough.
