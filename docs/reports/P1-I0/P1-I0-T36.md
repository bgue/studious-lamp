## Learnings (proposed)
- The `Edit` tool can drop a space when a replacement ends with a trailing space (`media = ` became `media =`). The
  damage is silent until a formatter runs. After an edit whose `old_string` or `new_string` ends in a space, read
  the changed line back, or run `ruff format --check` on the file before `just check`.
- Ticket Step 2 says to remove the `pathlib` import only when ruff reports it unused. In practice it is unused as
  soon as the annotation changes, so the step could say "remove it in the same edit as the annotation change".
  The result is the same, and ruff F401 confirms it.
