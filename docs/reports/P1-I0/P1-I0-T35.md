## Learnings (proposed)
- Swapping an import's module name can change its sort position. Ruff then reports I001 on the
  block, so a ticket that says "replace the import line" should also say "the import block may need
  re-sorting". Here `tl_adapters.db` sorts before `tl_adapters.objectstore`.
- The third acceptance command reports 407 passed, not the 397 the ticket cites plus "whatever this
  ticket adds" (this ticket adds no tests). The 10-test difference probably comes from tests merged
  on the branch since the 397 figure was measured. Worth refreshing the baseline in the ticket.
