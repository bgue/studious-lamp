## Learnings (proposed)
- A full `uv run pytest packages/tl-cli -q` takes about 5 minutes 20 seconds, which is longer than the 120-second foreground Bash limit. Run it in the background and write output to a file.
- The ticket's Context list does not include `packages/tl-cli/tests/auth_support.py`, but the provided test imports from it. It exists on the branch and was used unchanged.
- `test_cli_serve_tui.py` expects a TUI call dict without `signed_in`, but `tui.py` (from P1-I0-S5b) already passes that key. Any ticket that runs the whole `packages/tl-cli` suite will hit this until someone fixes the test or the TUI.
