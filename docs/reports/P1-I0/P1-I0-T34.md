## Learnings (proposed)
- A shell `cmd | tail -N; echo $?` reports `tail`'s exit status, not the command's. Use `set -o pipefail` or `${PIPESTATUS[0]}`, or redirect to a file, when a green exit code matters. My first `just check` run printed `EXIT=0` from `tail` and I re-ran it to capture the real status.
- `main.py`'s root callback already imports `DbTarget` and `as_target` from `tl_adapters.db`, so the target type is already in place for this swap. Other `tl_cli` modules still import the SQLite `open_uow` (`file.py`, `pset.py`, `link.py`, `wf.py`, `feed.py`, `schema.py`, `file_reconcile.py`, `extypes.py`, `extypes_quarantine.py`, `proposal.py`), and `lake.py`, `backup.py` and `webhook_common.py` import SQLite-only helpers. They are outside this ticket's Allowed paths and were left alone. A URL passed to them will still be treated as a file name until they get the same swap.
