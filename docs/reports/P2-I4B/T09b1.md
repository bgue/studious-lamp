## Learnings (proposed)
- An inspection cannot be dated before its scaffold's registration day (`valid_time`), and `RegisterScaffold` takes no date. Due-list tests through the API therefore need a projection write of `next_due_on` (done in the seed; documented in the module docstring).
- A scaffold's `key` is read from `cur_core_record`, not from `cur_scaffold_scaffold` (the punch seed does the same).
- `just check` on a fresh worktree: pyright OOMs at the default Node heap; `NODE_OPTIONS=--max-old-space-size=8192` fixes it.
