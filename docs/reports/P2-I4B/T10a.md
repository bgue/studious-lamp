## Learnings (proposed)
- A blocked readiness evaluation raises a blocking `ready` constraint on the IWP. A later passing evaluation clears it. A demo that moves an IWP to Ready/Issued after a red check must re-evaluate after the green.
- `make_uow_factory(target)()` opens a write unit of work by default. A read made inside an open write unit of work on SQLite raises `LockTimeoutError` ("ledger write lock was busy"); use `open_uow(readonly=True)` for reads.
- A scaffold with no state row (just registered) has a NULL `status` in `cur_core_record`; S1's `World.state` maps that to Requested. A driver reading state directly needs the same mapping.
