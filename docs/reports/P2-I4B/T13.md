## Candidate learnings
- A module's `Defined`-style event appended through `create_module_record(extra_events=...)` cannot name its own stream id; append it after the envelope in the same unit of work when the catalog requires `record_id`.
- Scenario-style tests that list event types by hand are the only place such a payload gap shows; the S1 command tests did not check the catalog schema of the payload.
