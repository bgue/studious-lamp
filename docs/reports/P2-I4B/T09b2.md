## Learnings (proposed)
- `TagScaffoldGreen` records a `pass` inspection, so a green scaffold has `inspection_count` 1 from the tag alone; the ticket did not say so.
- The due list cannot be non-empty through commands on the test day: an inspection dated today sets a next-due day in the future. A non-empty due list needs the projection write the ticket forbids outside the hidden case, so the API equality test compares an empty due list.
- `ruff format` reflowed signatures in three of my files; run `ruff format` before `just check`.

## Open questions / Blocked
