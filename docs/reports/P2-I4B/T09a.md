## Learnings (proposed)
- `tl_api.errors` has no row for the scaffold `ScaffoldError` classes. A domain refusal at the door (for example a second scaffold for one request, `ScaffoldRuleError`) returns 500 `internal_error`. `test_error_table.py` scans only `tl_core`, so it does not catch this.
- `_module_specs` reads `model`, `handler`, `access` only, so `ScaffoldCommand` satisfies it with no change.
- Module role `derive` gives every `user` account the `user` word for each module unless an explicit grant exists. A viewer grant on a module therefore removes `register`, which is the easy way to build a "no word" person.
