## Learnings (proposed)
- `just check` in a fresh worktree took longer than the 120 s foreground limit; run it in the background and wait on the process, not the log.
- Pitfall avoided: `"" in "=+-@"` is True in Python, so the CSV formula guard uses a tuple of prefixes (`startswith`), not a substring test. Worth a line in the views pattern note.
- A `pgrep -f "just check"` wait loop matches its own bash command line and never exits; wait on the PID instead.
