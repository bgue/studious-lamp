## Learnings (proposed)
- `register(name, ...)` raises unless `name` is in `ORDER` (registry.py).
- Only 1 of the 4 P200 scaffold requisitions is Approved; a demo that wants scaffolds in all four states needs the requisitions section to approve more (a change to its `FINAL`, which moves other counts).
- Whole-ledger hashes over a partial section list differ run to run (wall-clock `recorded_at` in some sections); fingerprint a section's own streams.
