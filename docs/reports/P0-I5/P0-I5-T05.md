## Learnings (proposed)
- An `Edit` on a file fails with "modified since read" if a Bash `sed -i` changed that file after the Read, even when the Read was the same session. I ran `sed -i` on the annotations first and then tried `Edit`; re-reading the file fixed it. Run the sed after the Edits, or re-read after it.
- `just test-parity` prints `dev up: skipped MinIO (no Docker daemon); the fs object store is used instead` on a machine without Docker. It is harmless for these tests, but it looks like a failure at a glance.
- The `uow` helper in `test_expected_links.py` is annotated with the `tl_core.uow.UnitOfWork` Protocol, not a SQLite class, so recipe item 1 (`SqliteUnitOfWork` → `BaseUnitOfWork`) does not apply to it. The annotation was left as is and pyright is clean.
