## Learnings (proposed)
- `read_row` asserts `row["voided"] == 0` and `== 1`. On Postgres the column is boolean and the assertions pass only because Python `False == 0` and `True == 1`. The assertions were left unchanged as the ticket requires. A future test that needs the real type should assert `is False` or `is True`.
- `psets_json` comes back as a string on Postgres (`json.loads` works in `test_update_psets_emits_changed_mapping`), so the column is text, not JSONB, on both dialects.
- `uv run ruff check --fix` reported "Found 4 errors" on the converted files before `ruff format`; the next `ruff check` was clean. I did not capture which rules fired, so the cause is unverified (most likely line length from the longer annotations).
- The Edit tool requires a fresh Read after a Bash `sed` has changed a file, even when the Bash command ran in the same session.
