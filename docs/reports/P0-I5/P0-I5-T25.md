## Learnings (proposed)
- The ticket's Context and Interfaces say a helper exists in the stub when it does not. Before writing a ticket, check that each helper it names exists in the file it names (here `_moment`).
- Each command body keeps its result inside the `with service_errors():` block and calls `fail(...)` there, so no name is assigned inside a `with` that may swallow an exception and then read after it. The `replay` branches follow the same pattern.
