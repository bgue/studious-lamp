## Learnings (proposed)
- A stub docstring with a regex escape such as `\s` compiles with a `SyntaxWarning` that shows up on every run of the script. When copying a spec docstring verbatim, escape the backslashes (`\\s`) so the rendered text is unchanged. Running `pytest -W error::SyntaxWarning` catches it.
- `git diff <branch> -- .` does not list untracked files. The acceptance diff stat is only complete after the new `tests/tools/` files are committed.
- Every `uv` command prints `warning: The UV_NATIVE_TLS environment variable is deprecated`. It is harmless noise; `UV_SYSTEM_CERTS` is the replacement the warning names.
