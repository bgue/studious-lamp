## Learnings (proposed)
- The Postgres runs of the two property files are much slower than SQLite (about 52 s for the pair against about 5 s on SQLite), because each Hypothesis example creates a new Postgres schema. CI time budgets for `just test-parity` should allow for this.
- `just dev up` in this environment prints `skipped MinIO (no Docker daemon); the fs object store is used instead`. The parity run still passed, so this is informational, not a failure.
- `test_reserve_range_is_a_stub` has no adapter fixture, so `--adapters` never parametrises it and `just test-parity` (marker-based) deselects it. A ticket that quotes a parity total should count it as a non-database test.
