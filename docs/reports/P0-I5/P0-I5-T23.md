## Learnings (proposed)
- AGENTS.md's tier table points the implementer at `docs/build-spec/01-tiers.md` §4 as the "read next" file, while the ticket's Context list (and the orchestrator's instruction) names only the ticket's own files. I followed the Context list and did not open §4. A supervisor may want the two reconciled, or the ticket to list §4 explicitly.
- `threading.Condition.wait_for(predicate, timeout)` returns the predicate's final value, which makes `wait_for` a one-line method. Holding the same condition for all shared state (accepted, rejected, script, seen) kept the lock story simple.
- The handler's `Content-Length` read uses `get(..., "0") or "0"`: an empty value makes `int("")` raise inside the request thread, which drops the connection instead of answering.
