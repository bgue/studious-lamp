## Open questions / Blocked
none for the acceptance criteria. Two points the specification does not cover, handled as follows; the supervisor may want to confirm them:
- The index Summary cell is the event's `title` as given, not pipe-escaped (the spec says `<title>`). A title containing `|` would break the index table. The provided tests and the specification are silent on this; the current generator derives titles from first sentences, so it is unlikely to matter.
- A JSON Schema `type` list with no string entries (for example `[]`) falls back to the `anyOf` options, then to `any`. The specification does not define this case.
