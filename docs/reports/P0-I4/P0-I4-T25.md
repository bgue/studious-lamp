## Learnings (proposed)
- `typer.testing.CliRunner.invoke` catches exceptions and returns them on the result, so a command that raises `NotImplementedError` does not fail a test that only checks side effects. `test_it_does_not_change_the_store_or_the_ledger` passed against the stub for that reason. A test that asserts only "nothing changed" on a CLI command should also assert the exit code, or it passes vacuously. Suggest adding `assert result.exit_code == 0` (or the expected code) to such tests in future tickets.
- The ticket's `unknown` rule for the summary is ambiguous as written ("each"); stating which lines it governs (orphans and staging, matching the `ReconcileReport.listed` docstring) would avoid a guess.
