## Learnings (proposed)
- A pipe hides the exit code. My first `just check ... | grep ...; echo $?` reported grep's status, not `just`'s. The ticket's "do not pipe `just check` into `tail`" rule is right for the same reason. Redirect to a file and read `$?` on the next line, or use `set -o pipefail`. I re-ran `just check` with a plain redirect to get the true exit code (0).
- The ticket's Context list does not include `packages/tl-core/src/tl_core/files/types.py`, which defines `ObjectNotFound` and `ObjectStore`. The provided test imports `ObjectNotFound` from the package `tl_core.files`, so I imported it from there too. This worked without reading `types.py`. The Context list could name the package `__init__.py` so implementers know the re-export exists.
