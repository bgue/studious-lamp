## Learnings (proposed)
- Piping a `just` command into `grep` and then reading `$?` reports the status of the last pipe stage, not of `just`. Redirect `just check > log 2>&1` and read `$?` directly to get the real exit code. The ticket already says not to pipe `just check` into `tail`; the same applies to `grep`.
- The ticket's `events.py` import list (`time`, `httpx2`) omits `clean_params` from `tl_api.client.base`, which already drops `None` query values. Implementers either inline the filter (as done here) or add the import; naming `clean_params` in the ticket would remove the ambiguity.
