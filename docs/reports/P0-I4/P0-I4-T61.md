## Learnings (proposed)
- `str(Path("./dev/data/tokens.json"))` is `dev/data/tokens.json`: `Path` drops the leading `./`. The stub keeps `DEFAULT_TOKENS = "./dev/data/tokens.json"` and the wrapper passes `str(tokens)`, which is what the provided test expects (`"dev/data/tokens.json"`). Anyone who passes the argv through as a raw string would fail that test.
- The `Edit` tool refuses a file that was read through `Bash` (`cat`); it needs a `Read` call on the file first. Harmless, but it costs a round trip.
- `tl_tui.main.run` `ValueError` messages in this repo include only the URL (`--remote must be an http(s) URL, got ...`) and fixed strings; none echoes the token, so printing `str(exc)` is safe for the `--token` path.
