## Learnings (proposed)
- `just test` output contains non-text bytes (snapshot report), so `grep` on the saved log reports "binary file matches" and hides the summary lines; use `grep -a` when filtering a saved `just test` log.
- `tl_api.tokens.add_token` creates missing parent directories (`mkdir(parents=True)`). The provided default-path test depends on this (it writes `dev/data/tokens.json` into an empty temp dir), but the ticket text does not say so. Worth a line in the ticket template when a test depends on implicit directory creation.
