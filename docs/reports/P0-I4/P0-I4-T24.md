## Learnings (proposed)
- The ticket's `get` spec says to stream `opened.data` but not to close it. `OpenedFile.data` is a live BinaryIO, and the caller must close it. A line in the spec ("close `opened.data` after copying") would have saved a warning hunt. The supervisor decides whether this goes into `docs/memory/LEARNINGS.md`.
- Pytest reports an unclosed handle as `PytestUnraisableExceptionWarning` with the file name in it, not as a test failure, so a green run can hide it. Running the file with `-W error::ResourceWarning` shows it.
