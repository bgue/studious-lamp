## Tests added
None beyond the provided file. `packages/tl-api/tests/test_api_links.py` holds the 9 provided tests:
- `test_links_of_a_record_read_from_both_ends` — outbound and inbound links with labels, status and other_title; isolated record returns `[]`.
- `test_retracted_links_are_hidden_unless_asked_for` — retracted link hidden by default, shown with `include_retracted`.
- `test_an_unknown_record_is_404_on_every_per_record_route` — links, trace and expected-links return 404 `record_not_found`.
- `test_trace_is_a_tree_limited_by_depth_and_direction` — tree shape, depth limit and direction filter.
- `test_trace_parameters_are_validated` — invalid direction or depth gives 422.
- `test_expected_links_lists_what_is_missing` — a missing `references` expectation is reported with found/needed counts.
- `test_link_counts_include_zero_rows` — zero rows for unknown ids; at least one id required (422).
- `test_search_linkable_matches_key_or_title_in_scope_and_company` — scope and company matching, `q`, `exclude_id`, `limit` bounds, scope required.
- `test_every_link_route_needs_a_token` — 401 without a token on all five routes.
