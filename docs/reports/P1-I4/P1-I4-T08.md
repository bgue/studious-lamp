## Learnings (proposed)
- A fresh worktree's first `just check` ran past the 120 s Bash timeout. Run it in the background or with a longer timeout from the start.
- `just check` includes `ruff format --check`. A `raise` hand-wrapped to match a STEPS comment is reformatted by ruff. Run `ruff format <file>` on the module before `just check`.
- `pgrep -f "just check"` matches other worktrees' processes too, so it is not a safe way to wait for your own run. Wait on the task output instead.
- The Acceptance count "19 tests on SQLite" is right; with `--adapters sqlite,postgres` the count is 20 because the one database test runs on both adapters.
