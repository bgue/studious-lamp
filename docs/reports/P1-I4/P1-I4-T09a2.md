## Learnings (proposed)
- The 200-row cut in the long-list test comes from the client's `compare_snapshots(limit=200)`
  (`Comparison.limited`), not from `compare_section_lines`' default `limit=500`. A reader who
  reads `schedule_text.py` alone would expect 500 rows. Stating the client limit in the ticket
  would have saved a check.
- In a git worktree `.git` is a file, not a directory, so a path such as `<worktree>/.git/../x`
  fails with "Not a directory". Use the worktree root path directly.
