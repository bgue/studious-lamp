## Learnings (proposed)
- The ticket's acceptance `grep -c '<'` counts every line with a `<`, including `<time>`-style placeholders in expected output. I removed the one I had written in prose so that the only remaining `<` is the deliberate `<snapshot_id>` in a command.
- The facts name `_tl_sync` as a lake table but name `cur_core_record` only inside the time-travel example. The copy-paste query in step 4 uses `_tl_sync` for that reason.
- The facts give no output line for `tl lake rebuild --yes`. A runbook author needs that line for the Expected field, so a fact such as "prints X" would save a round trip.
