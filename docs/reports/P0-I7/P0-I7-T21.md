## Learnings (proposed)
- A module-scoped fixture cannot use the function-scoped `ledger` and `lake` fixtures. The autouse `fixture_schemas` in `conftest.py` is also function-scoped, so the schema provider is inactive at module scope. A module-scoped ledger builder would need its own `use_provider(DirectorySchemaProvider(FIXTURES))`. This is why the test fixture is function-scoped.
- The guarded `lake_query` path accepts a leading `--` comment line before the single SELECT. The six demo files rely on this, and the tests confirm it.
