## Learnings (proposed)
- `just check` run in the background via the Bash tool returned an empty captured output while the job still ran; running the constituent steps in the foreground (ruff, pyright, `tl_schema.generate --check`, `tl_api.openapi --check`, `dev/tools/check_licences.py`) gave the same evidence. - `put_record_body` re-reads the record after `store_body` to get the post-write version. The ticket's step list does not say what to do if that second read returns `None`; I added a defensive `RecordNotFoundError` (unreachable in practice, since the record was just written in the same unit of work).
