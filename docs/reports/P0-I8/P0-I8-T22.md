## Learnings (proposed)
- `tl_mcp.resources.dump` is plain `json.dumps` with no pydantic support. A resource that returns a pydantic model must call `model_dump(mode="json")` first. The ticket does not say this.
- The provided test files are checked by pyright under the repo config. `tuple(row)` on a `.first()` result fails pyright with `Row | None`. A provided test should narrow Optional values (for example `assert row is not None`) before using them, or the provided file should be pyright-clean before it is handed out.
