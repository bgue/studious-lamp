## Learnings (proposed)
- `SchemaView` on the core schema loads with the process working directory unchanged (the ticket's escalation trigger did not fire). `SchemaView` returns `None` for unset `required`/`multivalued`, and `permissible_values` is typed `Optional`; coerce both.
- Under the MCP SDK, the template `tl://dev/event-sample/{event_type}` matches an empty last segment, so the empty-string case reaches the function and raises `ResourceError` (not `ResourceNotFound`).
- `linkml-runtime` is declared by `tl-schema`, not by `tl-mcp`; `tl-mcp` imports it transitively. The ticket names it, so I did not add a dependency.
- `dev/tools/scan_secrets.py` line 2 (103 characters) breaks `ruff check .` on `p0/i8c` and therefore `just check`. It needs a one-line wrap in a ticket whose Allowed paths include it.
- `just check` (with pyright) and the full `packages/tl-mcp` suite take longer than a 120-second foreground command; run them in the background.
