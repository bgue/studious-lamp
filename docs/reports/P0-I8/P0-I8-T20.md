## Learnings (proposed)
- The stub's `# ruff: noqa: F401` header hides unused imports, so `just check` stays green while stubs are still unfilled. Removing it at the end is the only check that imports are really used; the ticket could say so.
- `sync_lines` is documented as printing `registered` when the view's status is `active`. A conflict on an active version keeps the status `active` (the registration stays), so a refused edit prints `registered <ref>` followed by no issues. The conflict is only visible in `show` and `ls --status quarantined`. The brief (§31.1) says the change is reported once as a quarantine. See the open question below.
