## Learnings (proposed)
- The dev harness fixture is `dev_env` (`DevHarness`), not `env` (which is the product `McpHarness`). The ticket's test list says `env.structured("gen")`; the test module uses `dev_env`.
- `json.dumps` writes a Python `False` as `false` in the audit detail, so an audit assertion on a boolean argument must expect `"false"`.
- In `difflib` output the file on disk is `a` and the generator output is `b`. A marker added to the copy therefore appears as a removed (`-`) line in the diff, not an added one.
