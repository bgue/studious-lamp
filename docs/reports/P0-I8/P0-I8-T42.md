## Learnings (proposed)
- The tool function is named `rebuild_projections`, the same as the adapter function it calls. Importing the adapter as `from tl_adapters.db import rebuild_projections` would be shadowed by the tool's `def`. Import the module under an alias (`from tl_adapters import db as adapters_db`). The ticket's pasted snippet does not warn about this.
- The ticket's `may explore: (none)` conflicts with its own Escalation trigger, which requires checking the branch-point signature. The signature check needs a grep outside Context. The ticket could list `tl_adapters/db.py` as a Context file, or say "grep only".
- `create_record` writes no `cur_pset_values` rows, so "damage `cur_pset_values` rows" has nothing to hit on a fresh ledger. A ticket that wants that check needs to say how to create a pset row, or accept a sentinel row.
- `guarded` cuts `ValueError` text at 200 characters. The unknown-name message for the current 11 projectors is about 175 characters, so the valid list is complete. A longer projector list would be silently cut.
- The `Write` tool refuses an existing file that was only read with `cat` through Bash. A `Read` call is needed first, even when the content was already seen.
