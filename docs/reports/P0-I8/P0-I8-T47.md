## Learnings (proposed)
- The SDK's template router rejects a `{name}` containing `..`, a raw `/`, or `%00` before the function runs, and raises `ResourceError("Unknown resource: <uri>")`. Only names that match one path segment reach `safe_child`. The tests accept both texts; a test that expects exactly "no such document" fails for those URIs.
- `safe_child` accepts any name that ends with the suffix, so `0004-relay-orchestration.md` is a valid file name. The caller must append `.md` to the name, which is how "suffix included is not found" holds.
- `just check` stops at the first failing step (`ruff check .`), so pyright, `gen --check`, the openapi check and the licence check do not run. Run them one by one to see their output.
- The ticket's Tests section says the cut text "ends with `... (cut)`", while Step 4 says it ends with `\n... (cut)\n`. I implemented Step 4 exactly and the test asserts the exact text.
- Tests in `packages/tl-mcp/tests` import the harness as `from dev_harness import DevHarness`, not `tests.dev_harness`.
