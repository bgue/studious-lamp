## Learnings (proposed)
- The ticket's "imports to add" list omits `typing.Any`, which `lock` needs for its `bounds` annotation; the list should include it.
- A shell pipeline such as `cmd | grep -v ... ; echo EXIT=$?` reports grep's exit status, not the command's. Use `set -o pipefail` or capture the status before piping when a demo's exit code matters.
- `ruff format` reformatted parts of the new `config.py` after the first test run; running the formatter before the first test run avoids a second pass. Behaviour was unchanged (the test file was re-run after formatting, 26 passed).
