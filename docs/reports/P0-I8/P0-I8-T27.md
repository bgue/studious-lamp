## Learnings (proposed)
- `just check` on a fresh worktree took longer than the 120 s foreground timeout of the shell tool. Run it with `run_in_background` and poll its output file. Foreground `sleep` is blocked by the harness, so the poll has to use a short `timeout`-bounded loop or a background task notification.
- The ticket names "the record id" for `put_record_body` but not the dict key the record carries. The test fake (`packages/tl-tui/tests/fakes.py`) uses `record["id"]` for the id and `record["key"]` for the key, and the modal follows that. The ticket should name the key.
