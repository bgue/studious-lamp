`guards.dependent_permits(conn, isolation_id) -> list[Mapping]` reads **events**, no table: statement 1 selects the
link and unlink events whose payload text matches the isolation id (`CAST(payload AS TEXT) LIKE`, then exact test in
Python, ordered by seq); statement 2 reads the status of the permits still linked. Two statements however many
permits, plus one `is_hidden` per dependent in the handler. Blocking stored states: Approved, Active, Suspended
(Lapsed is Active shown late); Handed back and later do not block. Hidden dependents are one phrase.

## Decisions to check
Link and Unlink take no `expected_version` (no state moves). Apply requires `method`, `lock_number`, `tag_number`.
Link/Unlink refused only for Active or Lapsed (spec); a Requested or Approved permit takes them.

two apart; the code path never calls `require_word`.
