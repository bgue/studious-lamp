## Learnings (proposed)
- A request for a permit whose for-record a requester cannot read is refused by the handler with `no record with that id`, so a restricted-for-record permit has to be requested by a reader of that record. Its approver must also read it, and the MCP reads hide it from everyone, so the fixture needs a restricted reader for each step.
- `tl_mcp` tests take `utcnow` from the tool module (`tl_mod_permits.tools.utcnow`); patch that name to test Lapsed, since the views read `now` from the call.
