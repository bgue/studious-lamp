## Learnings (proposed)
- `tl permit --help` renders commands inside a Rich panel, so each command line starts with `│`; a `^\s*verb` regex never matches. Match `^[│ ]*verb\s`.
- A restricted permit for tests: `world.hidden_record()` then `world.request("dora", for_record_id=...)`; the permit inherits the restricted class. The key is readable with `world.scalar("SELECT key FROM cur_core_record WHERE id = :i", ...)`.
