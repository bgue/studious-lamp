## Learnings (candidates for LEARNINGS.md)
- `hot_work` cannot be issued without a gas test (`gas_test_missing`); the tests use `work_at_height`, which needs only its precautions.
- Every account role derives `read` on every module (`schema/settings/module-roles.yaml`, `derive`). So "no `permits.view`" is tested with an unknown `agent:` actor on a dev ledger, as `test_req_read.py` does. An account needs at least one role (`InvalidAccountError`).
- Permit handlers read `tl_core.util.utcnow` at call time, so one monkeypatch of that name moves the handlers and the CLI reads together.
- Only the SQLite adapter was run. The Postgres parity run was not executed.
