## Learnings (proposed)
- `command_index()` fails with a duplicate-name error when a test stand-in reuses a real module's name, and a fine word that is not in `schema/settings/access-words.yaml` fails with `AccessWordError`. A ticket that asks for new fine words in a test needs the table patched, or it needs to say so.
- "Nine installed modules" is not the same as the modules a pin list reports: `legacy` has no words, so any list of modules with commands is eight.
