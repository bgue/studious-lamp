## Learnings (proposed)
- `just check` took longer than the 600 s foreground limit of the Bash tool in this worktree (it was moved to the background). Run it in the background, redirected to a file in the scratchpad, and poll the file; do not expect it to return in one foreground call.
- The `ruff format` step inside `just check` reports `1289 files already formatted`, so the whole tree is checked, not only the touched files. A single-file `ruff format` before committing is enough to keep the diff clean.
