## Learnings (proposed)
- `just check` ran for well over the 120 s tool timeout in this worktree; it finished cleanly when run in the background with output redirected to a file. Pyright is the slow step. Implementers should expect to background `just check` rather than wait on it in the foreground.
- The pasted `RaiseArgs` interface in the ticket omits the inherited `note` field from `_Args`. The STEPS mention `args.note`, so the mismatch was harmless, but a pasted interface that omits base-class fields can look like a missing field to an implementer.
- `ruff format` re-wrapped one `Problem(message=...)` call in `status.py` after the first write; running it before the first `just check` avoids a second edit.
