## Learnings (proposed)
- The ticket's Depends-on line lists T10a to T10d as merged but not T09a, while the Context line
  says `thread.py` is "complete after T09a". T09a's `thread show` and `thread post` are needed by
  three of this ticket's acceptance tests. Listing T09a under Depends-on with its merge state
  would have shown the gap before the implementer started.
- In `test_summarise_posts_a_counted_summary`, the setup `thread post` is not checked for exit
  code. When it fails, the error surfaces only at `/summarise` as `empty_thread`, which points at
  the planner rather than at the failed post. Checking the setup exit code would make the cause
  visible.
- The `Edit` tool refuses an edit to a file that was only read via `cat` in Bash; a `Read` of the
  file is needed first.
- The ticket's Acceptance says "9 pass", but `test_cli_thread_dispatch.py` has 10 test functions
  (all 10 are collected). The count should be corrected to 10 in the ticket.
