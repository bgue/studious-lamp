## Learnings (proposed)
- The ticket's expected count "5 + 13" for the two files does not match the provided file, which has 3 tests in `test_compose_text.py` (16 in total). A ticket's expected count should be taken from `--collect-only`, not written by hand.
- `_refresh_popup` has no docstring in the stub, only the `STEPS` comment. A Haiku implementer who expects a docstring to exist (as on `ComposerScreen._refresh_popup`) will need a moment to find the right anchor for an edit.
