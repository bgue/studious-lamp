## Learnings (proposed)
- `create` passes `**body` into `CreateRule` after `actor=`, `source=` and `scope=`. A top-level JSON key named `actor`, `source` or `scope` raises Python `TypeError: got multiple values for keyword argument`, which `service_errors()` does not catch, so the user gets a traceback rather than `error:`. Not exercised by the provided test (I did not run it). See Open questions.
- `ruff format` on a file the implementer has already read marks it changed on disk, and the next edit tool call asks for a re-read. Harmless, but worth knowing when formatting mid-edit.
