## Learnings (proposed)
- The first foreground run of the legacy pytest command (both adapters, 83 tests, about 5 minutes) exited with code 144 after printing only dots and no summary. Re-running it in the background with output redirected to a file completed normally (83 passed, exit 0). A foreground Bash call that runs this long may be cut off; use `run_in_background` and poll the log.
- Foreground `sleep` is blocked by the Bash tool, and no Monitor tool is available in this session. Polling with `timeout 115 bash -c 'until grep -q "^EXIT=" log; do sleep 5; done'` works within the limit.
