## Learnings (proposed)
- The `submit` refusal for a breaking draft reads `error: <ref> makes changes that are not allowed in place: ...`. It never says "breaking"; a ticket that asks for that refusal should name the text.
- The 4.0.0 draft is made from the 3.2.0 fixture, so it also drops `actuator_make` (a deprecation); it still classifies as worst breaking.
- `export-git` writes registry-published versions only. The 3.2.0 fixture is in force from the schema directory, so only 3.3.0 is exported and `import-git --dry-run` reports it `unchanged`.
- A `just demo` run over both backends takes about 4 minutes (each `tl` call is a `uv run`). Run it in the background; a foreground call times out at 120 s.
