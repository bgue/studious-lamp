## Learnings (proposed)
- A rule's `InvokeAction` target must be a record id. A key gives `Rule.Blocked` with "a target is not a record of this scope", which is visible only in the event payload; the feed card says just "blocked a rule".
- The publication event is `DerivedDocument.Published` (usable in a rule's `when.event_types`).
- `tl load bronze` needs `--include-confidential` for every copy, internal runs too. Its error text says "include_confidential".
- Legacy statuses go into a description, not a revision, so `mart_document_status` shows status `-` for them.
- `tl_lake/sync.py` reads everything as the LOWEST reader: restricted documents never reach `tl lake`, for any reader.
- Marts are `mart_document_status`, `mart_document_issues`, `mart_document_turnaround`, `mart_schedule_history`, `mart_float_trend`; `tl lake mart ls` omits a mart with no source rows.
- `p1_i3_demo.py prepare` fails with FileNotFoundError when its directory does not exist.
