## Learnings (proposed)
- A rule's `InvokeAction` target must be a record id. A key gives `Rule.Blocked` ("a target is not a record of this scope"), visible only in the event payload.
- The publication event is `DerivedDocument.Published`.
- `tl load bronze` needs `--include-confidential` for every copy; a restricted run cannot be bronzed.
- Legacy statuses go into a description, not a revision, so `mart_document_status` shows status `-`.
- `tl_lake/sync.py` reads as the LOWEST reader: restricted documents never reach `tl lake`, for any reader.
- `mart_schedule_history` needs Published snapshots; `tl lake mart ls` lists a mart with 0 rows once its table exists.
- `tl load plan` needs a Profiled run; `tl load void` needs `--reason`.
