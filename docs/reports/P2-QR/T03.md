## Learnings (proposed)
- The provided test files under `docs/tickets/*/provided/` are excluded from ruff, but the copy a ticket asks for in `tests/` is not, so a provided test that is not lint-clean fails `just check` once it is copied. Ticket authors should either write provided tests lint-clean or name the ruff exclusion in the ticket.
- The ticket's Context list names `tl_core.qr.types` but not `tl_core.confidentiality` (where `Viewer` and `LOWEST` live); the provided test imports them; I grepped `confidentiality.py` to confirm `Viewer` and `LOWEST` exist.
