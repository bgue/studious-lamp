# P2-QR-S3: the scan page `/web/q`, the miss counter, the log filter

## Deviations (first)
1. **Signed-out bounce is a 303, not a rendered page.** `AuthenticationMiddleware` (`tl_api/auth.py`, not in
   the allowed paths) already 303s every signed-out `GET` under `/web/` to `/web/sign-in` before any route
   runs, so no lookup happens signed-out. `WebHeadersMiddleware` (`app.py`) adds `?next=` to that Location
   for a well-formed ASCII segment. A well-formed code therefore sits in the sign-in URL query; the log
   filter redacts `next=/web/q/...` (plain and `%2F`).
2. Agents get 401 from the middleware, not the guard's 403 (`guard("qr.read")` stays as the second wall).
3. Edits outside the list: `base.html` (script tags in `{% block scripts %}`), `sign_in.html` (hidden
   `next`), `tl_api/app.py` (insecure-dev warning logs a redacted path), pin files below.
4. **Referrer policy (review F1, F2, amends item 5):** `no-referrer` on `/web/q/<code>` answers (card, miss,
   429, bounce) and `POST /web/q`; `strict-origin` on `GET /web/q` and on `/web/sign-in` when `next=` is
   present, because under `no-referrer` a browser form POST sends `Origin: null` and the origin check
   refuses it. A no-referrer answer renders no CSRF token and no sign-out form (`render` in `app.py`).

## The miss page, byte-equal evidence
`test_five_readers_one_card_or_the_one_miss`: for the plain user and the admin, a malformed, an unknown, a
revoked, an expired, a hidden, a no-view-word and a no-provider code give the same status, bytes and headers
(one session each). Across readers the bytes differ only by the session's own CSRF token. No `Set-Cookie`.

## Limits
`MISS_LIMIT_SESSION = 10`, `MISS_LIMIT_ADDRESS = 30`, `WINDOW_S = 600`, `MAX_KEYS = 10_000`. A lookup is
reserved (counted) under the lock before the resolver runs and a hit refunds it (review F3), so a burst
cannot pass the limit; the 11th lookup gets 429 (`scan.LIMITED_TEXT`, `Retry-After`). Keys: sha256 of the
token and `ratelimit.client_key` with `settings.trusted_proxy_header`. A malformed typed code is a miss.
