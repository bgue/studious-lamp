## Learnings (proposed)
1. Textual 8.2.8 cuts non-priority App bindings at a ModalScreen (`Screen._modal_binding_chain`). `priority=True` reaches the app. A priority binding whose `check_action` returns False falls through: `App._check_bindings` returns False and `on_event` forwards the key to the focused widget (Input's delete-right).
2. After a palette dismisses, focus returns to the widget that had it before the palette opened. A `check_action` keyed on focus also gates palette-run actions, so the key needs its own action name.
3. Help screen and palette were not clipped: the help box scrolls, and the palette list is an `OptionList`. The F1 and palette tests read only the first screen of text.
