## Learnings (proposed)
- Handling `DataTable.RowSelected` on the register screen works without a priority binding: Enter opens the record, the filter `Input` keeps its Enter, and the cursor does not move.
- A fake's default form metadata (the valve form) has no `doc_type` or `discipline` enum, so a test of plain code words must set `metadata_by_type["documents.Document"]`; otherwise the codes fall back and the test passes for the wrong reason.
- `ruff format` and `ruff --fix` on a file that was read earlier print a "modified a file you've previously read" notice; the file content is only what the formatter produced.
