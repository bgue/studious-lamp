## Open questions / Blocked
1. `app.display` collides with Textual. `App.display` is Textual's own property; `app.display = DisplayMode()` raises
   `StyleValueError` (checked on textual 8.2.8). So `mode_of` can never find the mode on a real app: it returns a fresh
   plain `DisplayMode` each call, and an admin toggle would not persist. I implemented `mode_of` literally (`getattr` plus
   `isinstance`, else plain). Decision needed: the attribute name (for example `display_mode`). That is a one-line change
   in `mode_of` and in the interface text.
2. Calendar refs are not matched. The clock text writes `calendar {clock.calendar}`, and that value is `code@version`.
   `find_technical("... calendar P123-default@1 ...")` returns `[]`, because `CALENDAR_ID_PATTERN` (`cal:`, `calendar C-`)
   and `CALENDAR_VERSION_PATTERN` (`@v3`) do not match it. I did not add a pattern (the ticket's list is the contract).
   Decision needed: add a `calendar <code>@<n>` pattern.
