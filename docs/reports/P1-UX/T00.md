## Learnings (proposed)
- Pyright rejects `app.display_mode = ...` on a Textual `App`, and ruff B009/B010 reject `getattr`/`setattr` with a constant name. The test uses a pyright ignore with a reason.
- A calendar-ref pattern with no lookbehind double-reports dotted package refs. Check overlapping patterns when `find_technical` returns every pattern's hits.
