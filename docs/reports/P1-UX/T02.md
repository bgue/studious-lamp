## Learnings (proposed)
- `just check` ran past the 120 s foreground limit and was moved to the background; it finished cleanly. Run it in the background or with a longer timeout.
- Before running the gate, grep the test directory for every raw token the change removes (here `ControlValve`, `BAD`, `number violation`, `class `). The status-line expectation was not named in the ticket and only surfaced in the gate.
- `FakeClient.add_stored_record` was enough for Enter to open the record screen; `fakes.py` did not need a change.
