## Goal
Five GET routes (embedded and remote, as the other awp reads) over merged readers: one IWP's earned progress, the progress roll-up, the two KPI tiles, per-IWP counts (Ready checks, open blocking constraints, state-since) for the IWP log (T06c1), and the record hash a sign-off carries (T06a, D30: the CLI has `iwp hash`, a remote screen needs the same read; the handlers stay the gate). One word `document.read`, like the other awp reads; the viewer is the request's.

## Brief references (pasted)
Routes (project path as `routes/awp.py`; operation ids are the client method names of T11b):
- `GET /projects/{project}/awp/iwps/counts` (`list_iwp_counts`) -> `list[IwpCountRow]`: `number`, `state_since: str|None` (`cur_workflow_state.entered_at` as `YYYY-MM-DD`, `None` for a Draft with no row), `ready_ok: int`, `ready_total: int`, `evaluated: bool`, `open_blocking: int`, by number, at most 500, viewer-visible IWPs only. The reader is the new `tl_mod_awp.iwp_counts.iwp_counts(conn, scope, *, limit=500)`: `iwp_views.iwp_list` rows, then one batch of `look_ahead_view._readiness(conn, ids)` and `_open_blocking(conn, scope, None, set(ids))`, one `SELECT state_since` for the page; never a statement per row besides what `_open_blocking` already does. Mount this router BEFORE the `awp` router in `app.py` (else `{number}` takes `counts`).
- `GET .../awp/iwps/{number}/progress` (`get_iwp_progress`) -> `IwpProgress`: `number`, `pct: Decimal`, `edition: str`, `items: list[{key, pct, steps: list[str], hours: Decimal|None}]`, `notes: list[str]`; from `iwp_views.iwp_detail(...)` (None is 404 `record_not_found`, one text for missing and hidden) then `engine.earned_fraction(conn, detail.id, viewer=confidentiality.current_viewer())`.
- `GET .../awp/progress/rollup` (`get_progress_rollup`) -> `RollupBody` = `ProgressRollup` as a pydantic model (`RollupBody.model_validate(dataclasses.asdict(found))`; fields `scope, as_of_seq, cwps, nodes, lines, notes`) from `progress_rollup(conn, scope, viewer=current_viewer())`.
- `GET .../awp/kpis` (`list_kpis`) -> `list[KpiTile]` from `kpis.kpi_rows(conn, scope, current_viewer())`.
- `GET .../awp/iwps/{number}/hash` (`get_iwp_hash`) -> `IwpHash{number: str, record_hash: str}` from `iwp_views.iwp_detail` (None is the same 404) then `handlers.signoff.iwp_record_hash(conn, detail.id)`; read as `awp_iwp_write.iwp_hash` does (`tl_cli/awp_iwp_write.py` 346-355).
- Every payload key is declared in the route models; no `id`, `facts_hash` or hidden-record text. A hidden IWP is absent from counts and 404 on progress with the same body as an unknown number.
