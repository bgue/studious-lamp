# Reading accepted links from the SQL tables

Table and column names are those generated by `gen-sqltables` from `schema/linkml/xray_4d.yaml` (see `xray_4d.sql`).
One database per project model (Activity.task_code and Element.global_id are keys across the tables).

Accepted links with their elements (one row per element):

```sql
SELECT l.id, l.activity AS task_code, l.role, e.elements_global_id AS global_id
FROM "ActivityLink" l
JOIN "ActivityLink_elements" e ON e."ActivityLink_id" = l.id
WHERE l.status = 'accepted'
ORDER BY l.activity, e.elements_global_id;
```

The activities those links use, with the dates to write:

```sql
SELECT a.task_code, a.name, a.wbs_path, a.activity_type, a.activity_status, a.start, a.finish
FROM "Activity" a
WHERE a.task_code IN (SELECT activity FROM "ActivityLink" WHERE status = 'accepted')
   OR a.activity_type IN ('milestone', 'finishMilestone');
```

Accepted location / trade / zone per element (the newest accepted row wins when there are several):

```sql
SELECT element, attribute, value
FROM "Assignment" s
WHERE s.status = 'accepted'
  AND s.created_at = (SELECT MAX(created_at) FROM "Assignment" t
                      WHERE t.element = s.element AND t.attribute = s.attribute AND t.status = 'accepted');
```

Proposed rows waiting for review (report them as skipped):

```sql
SELECT 'link' AS kind, id, activity AS subject, source, confidence FROM "ActivityLink" WHERE status = 'proposed'
UNION ALL
SELECT 'assignment', id, element, source, confidence FROM "Assignment" WHERE status = 'proposed';
```

To run the bundled script from SQL, write the rows into a `LinkDataset` JSON (`activities`, `links` with `elements`
as GlobalId lists, `assignments`) and pass it as `--links`. The script only needs those three lists and `model`.
